# Blog Formatting Checklist

## Keep

- core arguments
- technical detail
- examples
- caveats
- the author's tone

## Improve

- paragraph length
- heading clarity
- term consistency
- list formatting
- comparison formatting
- quote placement
- emphasis restraint

## Common Transformations

### Dense explanation -> shorter paragraphs

Split when a paragraph contains:

- a definition and an example
- a system view and a model view
- a claim and its caveat
- a concept and an analogy

### Repeated contrasts -> list or table

Convert to a list or table when the post repeats patterns like:

- A vs. B
- stage-by-stage descriptions
- responsibilities by layer
- inputs vs. outputs
- before vs. after

### Important takeaway -> short quote

Use a blockquote for:

- one-sentence framing ideas
- the cleanest mental model in the article
- a short summary line that helps the reader orient

Do not use blockquotes for long explanatory sections.

## Terminology Style

- Bold named concepts on first strong mention when useful.
- Use inline code for exact technical labels.
- Reuse the same capitalization for the same concept throughout the post.
- Avoid inventing new terminology that the author did not use.

## CSS Heuristics

- Fix readability problems, not everything.
- If bold text looks harsh, tone down the CSS rather than removing emphasis from the article.
- Improve article spacing before adding decorative UI.
- Keep article-specific visual choices consistent with the site.
