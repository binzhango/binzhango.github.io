## Question

Closest key: given a dictionary with letter keys and lists of letters as values, find the closest key.

## Brief answer

“Closest key” needs a distance definition. A dictionary of letters and neighbor lists naturally describes a graph, so an illustrative interpretation is the nearest target key by number of edges. Use breadth-first search for unweighted edges and a deterministic neighbor ordering for ties. If the intended distance is lexical or numeric, this is a different problem.

## Detailed answer

```python
from collections import deque

def closest_key(graph, start, targets):
    targets = set(targets)
    queue, seen = deque([(start,0)]), {start}
    while queue:
        node, distance = queue.popleft()
        if node in targets: return node, distance
        for neighbor in sorted(graph.get(node, [])):
            if neighbor not in seen:
                seen.add(neighbor); queue.append((neighbor,distance+1))
    return None

assert closest_key({'a':['c','b'], 'b':['d']}, 'a', {'b','c'}) == ('b',1)
assert closest_key({'a':[]}, 'a', {'z'}) is None
```

This treats adjacency as directed and allows the start itself at distance zero. BFS visits each reachable vertex and edge once, excluding the sorting cost. For weighted edges use Dijkstra when weights are nonnegative; for an undirected graph insert reverse edges. Before coding in an interview, obtain a small input/output example that resolves what counts as a key, whether values are traversable nodes and how ties should be handled.

BFS explores all nodes at distance zero, then one, then two, so the first target removed from the queue has minimum edge distance. Marking nodes seen when enqueued prevents cycles and repeated work. Sorting each adjacency list gives deterministic traversal, but the exact tie policy is traversal order, not necessarily a global lexical order across every equally distant target.

For example, a lexically earlier branch can lead to target `z` before a later branch reaches target `a`, both at the same depth. If the requirement is the globally smallest target among the nearest distance, process the whole matching level and select the minimum. Clarifying this distinction is more important than silently assuming “deterministic” means “lexically smallest.”

The shown interpretation treats values as graph nodes even if they have no dictionary entry; they simply have no outgoing edges. Weighted distances require a different algorithm, and lexical distance requires a different problem definition. Ask for a concrete input/output contract, then test cycles, unreachable targets, start-as-target and ambiguous ties against that contract.
