## Question

For a long-context assistant, when is a 1M-token context window the right tool, and when should you use retrieval instead?

## Brief answer

Use a very long context when the task needs broad interaction among a bounded set of documents and the latency and cost are acceptable. Use retrieval when the corpus is large, frequently changing, permissioned, or only a small fraction is relevant. A hybrid often works best: retrieve a coherent evidence set, then reason over it in a long context.

## Detailed answer

Examples favoring long context include comparing all clauses in a small contract bundle or analyzing dependencies across selected source files. Retrieval is attractive for answering one policy question from millions of records, especially when access controls and freshness matter.

Compare both on the actual question distribution. Measure evidence coverage, citation correctness, multi-hop accuracy, abstention, cost, and latency. Retrieval can miss relevant evidence; long context can bury it among distractors, introduce conflicts, or exceed a useful attention budget. A million-token capacity is not a relevance guarantee. Cache stable prefixes when possible and reserve room for answers and tool results. Treat corpus selection, document ordering, and authorization as explicit steps in either design.

### Decide using evidence coverage

For “compare every indemnity clause across these twelve contracts,” selecting the complete bounded bundle may avoid retrieval silently omitting an important clause. For “what is today's baggage allowance?” over millions of changing policy pages, sending everything is both impractical and harder to authorize. Retrieval can select the latest applicable policy and expose exactly which evidence supports the answer.

A useful hybrid first retrieves candidate documents, expands neighboring sections or linked definitions, removes duplicates, and orders the evidence coherently. The answer stage receives enough context to reconcile conflicts rather than disconnected snippets. Evaluate with an oracle experiment: provide known-complete evidence and compare its answer quality with the retrieval pipeline. If the oracle succeeds but retrieval fails, improve evidence selection. If both fail, a longer window alone will not repair reasoning or instruction-following. Include adversarial distractors and conflicting dates; fluent output can conceal an ignored decisive passage.
