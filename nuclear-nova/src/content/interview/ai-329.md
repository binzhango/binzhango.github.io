## Question

What is the closed-form solution of linear regression, and when do you use gradient descent instead?

## Brief answer

For squared-error linear regression, a least-squares solution is $\hat\beta=X^+y$, using the pseudoinverse. If $X$ has full column rank, this equals $(X^TX)^{-1}X^Ty$, but explicitly forming the inverse is usually numerically inferior to QR or SVD. Use iterative optimization when data or feature dimension makes direct factorization impractical or when training is online.

## Detailed answer

The objective $\frac12\|X\beta-y\|_2^2$ has gradient $X^T(X\beta-y)$. Setting it to zero gives the normal equations. Rank deficiency means coefficients need not be unique, although fitted predictions are unique; the pseudoinverse selects the minimum-norm solution.

For dense data with $n$ rows and $p$ features, direct methods can require roughly $O(np^2)$ work when $n\ge p$, whereas each full gradient pass costs $O(np)$. Sparse, distributed, or streaming data often favors iterative solvers. Standardize features and select a stable learning rate; stop based on convergence and validation, not a fixed arbitrary number of steps. Ridge regularization improves conditioning, but changes the objective and usually leaves the intercept unpenalized.

### Solve without explicitly inverting a matrix

When X has full column rank, the algebraic expression is $\hat\beta=(X^TX)^{-1}X^Ty$. In implementation, solve the least-squares system using QR or SVD instead of computing the inverse: forming $X^TX$ squares the condition number and can amplify numerical error. If two columns encode the same feature, rank deficiency makes the inverse undefined, while SVD still supplies a minimum-norm solution.

For points (0,1), (1,3), and (2,5), include an intercept column so X has rows [1,0], [1,1], [1,2]. Then $X^TX=\begin{pmatrix}3&3\\3&5\end{pmatrix}$ and $X^Ty=(9,13)^T$, yielding intercept 1 and slope 2. Gradient descent approaches the same optimum for this convex objective with a suitable step size, but avoids a large dense factorization when features or observations are enormous. Compare conditioning, sparsity, precision, and convergence requirements before choosing the solver.
