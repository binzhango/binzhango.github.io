## Question

Your agent drifts after a long run and confidently works on the wrong thing. Diagnose it.

## Brief answer

Compare the agent’s current actions against the original goal, accepted changes and verified task state. Long-run drift often comes from lossy summaries, irrelevant context, untrusted instructions or a missing completion criterion.

## Detailed answer

Replay the trace around the first divergence. Inspect memory writes, compaction summaries and tool results for unsupported assumptions. Restore a compact authoritative task ledger with constraints, completed work, open questions and evidence links. Add milestone checks before costly or consequential actions, and stop repeated work that does not reduce an outstanding requirement. Test recovery on long sessions with interruptions, corrections and adversarial retrieved content.

Find the first incorrect transition, not merely the final bad answer. Compare the goal in the latest accepted user instruction with the goal recorded after each summarization or handoff. Look for a constraint that disappeared, a tentative assumption promoted to fact, or an external document instruction adopted as a new task. A long trace can appear productive while every subsequent action serves the wrong objective.

For example, an agent asked to diagnose a slow query may begin redesigning the entire database after reading a general architecture document. A task ledger should preserve “identify and fix this regression,” the permitted scope, the evidence already gathered and the test that would demonstrate success. Before a major action, require a brief check that it addresses an unresolved requirement in that ledger.

Recovery means restoring authoritative state and retaining useful verified work, not blindly restarting the whole task. Summaries should distinguish completed, attempted and unverified actions. Tool outputs should retain provenance and never overwrite the user's intent. Build long-session tests with interruptions, changed preferences and failed tools, then score goal adherence and repeated work. More context can help recover evidence, but adding a larger transcript without a clear priority structure can worsen the drift.
