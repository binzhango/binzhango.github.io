## Question

Your on-device model must emit valid, schema-conforming tool calls. How do you guarantee validity rather than hope for it?

## Brief answer

Constrained decoding can guarantee syntactic membership in a supported grammar or schema language, while post-generation validation enforces the full application schema. Neither guarantees that the chosen tool or argument values are semantically correct or authorized. Treat tool execution as a separate, permissioned step with typed validation and contextual checks.

## Detailed answer

Compile the supported JSON schema subset into token constraints and handle end-of-output correctly. Reject unsupported schema features rather than claiming complete coverage. Validate the parsed result again for types, bounds, required fields, and business rules. Resolve identifiers against available contacts, files, or app objects instead of accepting invented IDs.

For a send-message action, a valid JSON object with a recipient string is not enough: verify the recipient, current permission, message preview, and required confirmation. Set generation limits and return a recoverable error if no valid completion is reached. Test unicode escapes, nested structures, empty enums, long strings, refusal paths, and cancellation. Guided generation is an interface tool, not a replacement for an authorization boundary.

### Separate three kinds of validity

Syntactic validity means the output parses as JSON. Schema validity means it has the required fields and allowed types. Semantic validity means those fields refer to real permitted objects and satisfy business rules. Constrained decoding can enforce supported syntax/schema constraints, while only application checks can establish that `recipient_id` names the intended person and that sharing is authorized.

For a calendar tool, the decoder can restrict the operation name to an enum and require start/end strings. The validator must still parse time zones, reject end-before-start, resolve the actual calendar, and check permission. If validation fails, return a structured repair request to the model with a bounded retry count; never execute a partly valid object. Generation can also be interrupted, so a valid-prefix stream must not be committed before completion. Test adversarial strings and every supported schema feature against the exact tokenizer and grammar engine rather than assuming generic JSON support covers the whole schema standard.
