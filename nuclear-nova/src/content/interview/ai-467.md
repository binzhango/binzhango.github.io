## Question

Print the top view of nodes in a binary tree.

## Brief answer

Traverse the binary tree breadth-first while tracking each node's horizontal distance from the root. Record only the first node at each distance: breadth-first order guarantees it is at minimum depth. Sort distances from left to right for the top view; define a deterministic left-first tie rule.

## Detailed answer

```python
from collections import deque
from dataclasses import dataclass

@dataclass
class Node:
    value: object
    left: object = None
    right: object = None

def top_view(root):
    if root is None:
        return []
    queue = deque([(root, 0)])
    seen = {}
    while queue:
        node, x = queue.popleft()
        seen.setdefault(x, node.value)
        if node.left is not None:
            queue.append((node.left, x - 1))
        if node.right is not None:
            queue.append((node.right, x + 1))
    return [seen[x] for x in sorted(seen)]

assert top_view(Node(1, Node(2, right=Node(4)), Node(3))) == [2, 1, 3]
assert top_view(None) == []
```

For n nodes and w occupied horizontal distances, traversal is O(n), sorting is O(w log w), and memory is O(n) in the worst case. Tracking minimum and maximum distance can avoid sorting because binary-tree horizontal distances form a contiguous range. This is a tree algorithm; cyclic or shared graph nodes require a separate identity/visited policy.

### Why the first node wins

Assign horizontal distance zero to the root, subtract one for a left edge, and add one for a right edge. A node below the root along left-then-right returns to distance zero, but the root hides it from above. Breadth-first traversal processes shallower nodes before deeper ones, so `setdefault` records the visible node the first time a distance is encountered and ignores later hidden nodes.

For a root 1 with left child 2 and right child 3, and node 4 as the right child of 2, the distances are 0, -1, +1, and 0. The recorded map is `{-1:2, 0:1, 1:3}`, yielding `[2,1,3]`. A depth-first traversal with the same “first seen” rule could visit a deep node before a shallower competitor and return the wrong result.

Enqueuing left before right supplies a deterministic convention when distinct nodes at the same depth and distance are otherwise equally visible. Include a skewed tree, a single node, repeated values, and competing branches in tests. Values do not identify nodes; the algorithm relies on structural position, so equal values must not cause deduplication.
