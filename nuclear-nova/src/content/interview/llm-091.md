## Question

When performing SFT, should the base model be Chat or Base?

## Brief answer

Use an instruction-tuned checkpoint when you want to preserve existing assistant behavior with limited data; use a base checkpoint when you need greater control and can supply sufficient post-training data.

## Detailed answer

Neither is universally best. Further tuning a chat model can be data-efficient, but can also interfere with existing capabilities or formatting. A base model generally needs broader supervision to become a reliable assistant. Compare license, context support, target-task quality, and regression behavior using a small pilot, and preserve the checkpoint's tokenizer and chat template.

Start from the behavior you need to preserve. An instruction-tuned model already has conventions for roles, turn endings, refusals, and task following. A small specialist dataset can adapt one workflow while relying on those existing behaviors. Starting from a base model gives more control over assistant training, but a narrow dataset may leave many ordinary conversational situations uncovered.

Suppose the goal is to produce a structured incident summary. Compare small pilots from suitable base and chat checkpoints using the same independently held-out incidents. Measure field correctness, format validity, handling of missing evidence, and behavior on unrelated requests. Do not compare only training losses, because the initial distributions and examples' likelihoods differ.

Preserve the intended tokenizer and serialization for each candidate. A base checkpoint may not have a meaningful chat template, while a chat checkpoint may depend strongly on its trained role markers. Check licensing and serving support before investing in a run. Prefer the starting point that reaches the required behavior with manageable regressions and data cost; neither “more aligned” nor “less modified” is a universal reason to choose one.
