## Question

What’s the formula for the FFN (Feed-Forward Network) block?

## Brief answer

A standard position-wise FFN applies an input projection, nonlinearity, and output projection independently at each token.

## Detailed answer

Using column vectors:

$$
\operatorname{FFN}(x)=W_2\phi(W_1x+b_1)+b_2,
$$

where $x\in\mathbb R^d$, $W_1\in\mathbb R^{h\times d}$, and $W_2\in\mathbb R^{d\times h}$. The hidden width $h$ usually exceeds $d$. Gated variants use two input projections and multiply their outputs before projecting back; applying SiLU to a single projection is not the same as SwiGLU. Some architectures omit biases. Attention mixes tokens; the FFN mixes features within each token.

The same matrices are applied to every token position. For a batch of length $n$, the FFN can process all $n$ vectors together, but no token reads another token inside this operation. Information from other positions has already entered the vector through attention. The nonlinearity is essential: without it, two linear projections collapse into a single linear transformation, limiting the role of the expanded hidden space.

Ignoring biases, the two matrices contain $2dh$ parameters and require roughly $2dh$ multiply-accumulate operations per token. With $h=4d$, that is $8d^2$ parameters. The output returns to width $d$ so that it can be added to the residual stream. The intermediate activation of width $h$ contributes memory during training.

For a concrete shape example, a 768-dimensional token projected to width 3,072 becomes a 3,072-element nonlinear feature vector, then returns to 768 dimensions. In a gated FFN, a second expanded projection multiplies the first; this increases the number of matrices and changes the hidden-width choice for a matched parameter budget.
