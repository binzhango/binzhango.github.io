## Question

Estimate the KV-cache memory to serve a 70B-class model at 128k context. What do you do when it doesn't fit?

## Brief answer

State the checkpoint's layers, KV heads, head dimension, precision and concurrent sequences before calculating. For an illustrative 80-layer, eight-KV-head, 128-dimensional BF16 cache at 131,072 tokens, KV storage alone is 40 GiB per sequence.

## Detailed answer

The full-attention formula is $2BLTH_{kv}d_hs$. With $B=1$, $L=80$, $T=131072$, $H_{kv}=8$, $d_h=128$ and $s=2$, it gives 42,949,672,960 bytes. Add roughly 140 GB of BF16 weights for 70B parameters, activations and allocator overhead; do not confuse decimal GB with GiB. If the budget fails, reduce admitted context/concurrency, shard the cache where the runtime supports it, or evaluate KV quantization and retrieval/context compression. Sliding windows or latent attention change the architecture and cannot be assumed for an arbitrary checkpoint. Offloading can fit memory while destroying the latency target, so measure transfer cost.

### Derive the per-token footprint

Each layer retains a key and value for every past token and KV head. With the stated dimensions, one token consumes $2\times80\times8\times128\times2=327{,}680$ bytes across all layers, or 320 KiB. Multiplying by 131,072 tokens gives 40 GiB. Ten equally long concurrent sequences therefore require 400 GiB of cache alone, before weights and other memory.

This explains why a model that fits at short context can fail under a handful of long requests. Admission control should budget live cache by request length and expected growth, not merely count requests. Reducing context with retrieval may improve both memory and useful evidence density. Cache quantization trades memory for numerical error and needs task validation. Sharding distributes capacity but introduces communication; offloading introduces bandwidth and latency costs. Paged allocation reduces fragmentation and enables sharing, but does not reduce the mathematical storage of distinct live values. Inspect the exact checkpoint's attention architecture before applying the formula unchanged to latent or sliding-window attention.
