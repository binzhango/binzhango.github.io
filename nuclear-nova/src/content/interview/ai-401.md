## Question

Given allowed IP ranges as CIDR blocks plus explicit deny ranges, implement is_allowed(ip) efficiently for millions of checks per second.

## Brief answer

Compile allow and deny CIDRs into merged integer intervals, then use binary search; deny rules take precedence and no matching allow means denied. Keep IPv4 and IPv6 separate. Parsing addresses can dominate at millions of checks per second, so production hot paths should use pre-parsed integers and native or vectorized lookup rather than promise that pure Python reaches that rate.

## Detailed answer

```python
from bisect import bisect_right
from ipaddress import ip_address, ip_network

def compile_ranges(cidrs):
    groups = {4: [], 6: []}
    for cidr in cidrs:
        net = ip_network(cidr, strict=True)
        groups[net.version].append((int(net.network_address), int(net.broadcast_address)))
    result = {}
    for version, intervals in groups.items():
        merged = []
        for lo, hi in sorted(intervals):
            if merged and lo <= merged[-1][1] + 1:
                merged[-1] = (merged[-1][0], max(hi, merged[-1][1]))
            else: merged.append((lo, hi))
        result[version] = ([x[0] for x in merged], [x[1] for x in merged])
    return result

class IPPolicy:
    def __init__(self, allow, deny):
        self.allow, self.deny = compile_ranges(allow), compile_ranges(deny)

    @staticmethod
    def _contains(table, version, value):
        starts, ends = table[version]
        index = bisect_right(starts, value) - 1
        return index >= 0 and value <= ends[index]

    def is_allowed(self, text):
        try: address = ip_address(text)
        except ValueError: return False
        version, value = address.version, int(address)
        return (self._contains(self.allow, version, value)
                and not self._contains(self.deny, version, value))

p = IPPolicy(['10.0.0.0/8', '2001:db8::/32'], ['10.2.0.0/16'])
assert p.is_allowed('10.1.2.3') and not p.is_allowed('10.2.0.1')
assert p.is_allowed('2001:db8::1') and not p.is_allowed('192.0.2.1')
assert not p.is_allowed('bad') and not p.is_allowed('::ffff:10.1.2.3')
```

Compilation costs $O(R\log R)$ and each lookup $O(\log R)$ for merged range count R. IPv4-mapped IPv6 addresses are intentionally treated as IPv6 here; normalize them only under an explicit policy. Build a new immutable policy and swap it atomically for updates. Test overlapping denies, boundary addresses, `/0`, empty lists, malformed inputs, and concurrent readers.

### Why interval search answers the policy

A CIDR block becomes an inclusive integer interval. Sorting and merging overlapping or adjacent intervals removes redundant ranges without changing membership. For a lookup, binary search finds the last interval whose start is no greater than the address; membership is then one comparison against that interval's end. Evaluate allow membership and deny membership separately so an explicit deny always wins.

IPv4 and IPv6 use separate tables because their address spaces and parsing semantics differ. The sample intentionally does not reinterpret IPv4-mapped IPv6 addresses as IPv4, preventing an implicit policy bypass. At millions of checks per second, string parsing and Python overhead may dominate the logarithmic search; benchmark a native implementation or pass already parsed integer addresses through a trusted interface. Immutable compiled policies support safe concurrent reads and atomic updates. Validate `/0`, single-host prefixes, adjacent boundaries, malformed addresses, and nested denies. The algorithm provides an efficient lookup design, not a measured Python throughput guarantee.
