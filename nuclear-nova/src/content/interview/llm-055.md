## Question

Why do we need Cross-Attention?

## Brief answer

Cross-attention lets one sequence selectively read information from a different sequence or modality.

## Detailed answer

For translation, decoder states query source-language encoder states. For vision-language systems, text states can query visual features. Concatenating everything into one self-attention stream is an alternative, but cross-attention provides an explicit interface between representations with different lengths or encoders. Its usefulness depends on the architecture and task rather than being mandatory for all multimodal or retrieval systems.

A decoder answering “Which object is red?” needs to connect its current linguistic state to the relevant visual region. Cross-attention gives each text query a weighted read over image features without requiring image patches and text tokens to originate from the same encoder. Learned projections bring their feature widths into a compatible query-key space.

The same principle applies in translation: the next target word may align with a source word far from the source position corresponding to the previously generated word. A content-based read is more flexible than compressing the whole source into a single fixed vector or imposing a fixed one-to-one alignment.

There are alternatives. A decoder-only multimodal model can insert projected image features into its token stream and use self-attention. A RAG system can insert retrieved text directly into the prompt. Cross-attention is useful when explicit separation of source encoding and target generation matches the task or enables source-state reuse. Its additional projections, masks, and source-length-dependent computation must be justified by quality and serving constraints, rather than included merely because the application combines two data sources.
