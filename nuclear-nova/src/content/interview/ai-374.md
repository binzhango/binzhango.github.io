## Question

Implement non-maximum suppression. Then vectorise it.

## Brief answer

Greedy non-maximum suppression sorts boxes by confidence, retains the highest remaining box, and removes lower-scored boxes whose intersection-over-union exceeds a threshold. Vectorize the overlap calculation against all remaining boxes while preserving the sequential greedy selection. Class-wise NMS avoids suppressing different classes; crowded scenes may need a different suppression policy.

## Detailed answer

This NumPy implementation assumes finite continuous-coordinate boxes `[x1, y1, x2, y2]`, with nonnegative width and height. Equal scores retain input order.

```python
import numpy as np

def nms(boxes, scores, threshold=0.5):
    b = np.asarray(boxes, dtype=float).reshape(-1, 4)
    s = np.asarray(scores, dtype=float)
    if s.shape != (len(b),) or not 0 <= threshold <= 1:
        raise ValueError("invalid scores or threshold")
    if not np.isfinite(b).all() or not np.isfinite(s).all():
        raise ValueError("non-finite inputs")
    if np.any(b[:, 2:] < b[:, :2]):
        raise ValueError("inverted box")
    areas = np.prod(b[:, 2:] - b[:, :2], axis=1)
    order = np.argsort(-s, kind='stable')
    keep = []
    while order.size:
        i = int(order[0]); keep.append(i)
        rest = order[1:]
        wh = np.maximum(0, np.minimum(b[i, 2:], b[rest, 2:])
                           - np.maximum(b[i, :2], b[rest, :2]))
        intersection = wh[:, 0] * wh[:, 1]
        union = areas[i] + areas[rest] - intersection
        iou = np.divide(intersection, union, out=np.zeros_like(union),
                        where=union > 0)
        order = rest[iou <= threshold]
    return keep

boxes = [[0, 0, 2, 2], [0, 0, 2, 2], [3, 3, 4, 4]]
assert nms(boxes, [0.9, 0.8, 0.7]) == [0, 2]
assert nms([], []) == []
assert nms([[0, 0, 0, 0]], [1]) == [0]
assert nms(boxes, [1, 1, 1], 1) == [0, 1, 2]
```

A scalar implementation uses the same loop with one IoU calculation per candidate; vectorization removes Python's inner loop but not worst-case $O(n^2)$ work. Sorting costs $O(n\log n)$ and working memory is $O(n)$. Apply per class or explicitly choose class-agnostic behavior. Validate the threshold on small/overlapping-object recall rather than copying a default blindly.

### Greedy suppression preserves the highest score first

Sort candidates by descending score. Retain the current best box, calculate its intersection-over-union with remaining boxes, remove those above the threshold, and repeat. The vectorized code computes all comparisons against one retained box at once. It does not compare every pair independently and remove all overlaps, which could incorrectly discard both boxes.

For identical positive-area boxes, IoU is one, so only the highest-scored box survives when the threshold is below one. For disjoint boxes, intersection is zero and both remain. The implementation defines zero-union IoU as zero and uses continuous coordinates, so it does not add one pixel to widths. Those conventions must match the dataset and evaluator. Apply NMS per class when overlapping objects of different classes should both remain. In crowded scenes, greedy suppression can remove a real adjacent object; compare soft suppression or task-specific alternatives using crowded/small-object recall, not only overall precision.
