## Question

Implement a text chunker with overlap that never splits a semantic unit.

## Brief answer

Define semantic units first—paragraphs, sentences, Markdown blocks or AST nodes—then pack complete units into chunks. Overlap should reuse complete trailing units. A unit larger than the size budget makes “never split” and “hard maximum” incompatible; explicitly reject it or allow an oversized chunk rather than silently breaking the promise.

## Detailed answer

This implementation receives already segmented units, uses whitespace-token counts as an illustrative size measure, and rejects oversize units. Overlap is a maximum budget; it shrinks when necessary to admit the next unit.

```python
def chunk_units(units, budget, overlap=0):
    if budget <= 0 or not 0 <= overlap < budget: raise ValueError('invalid budgets')
    chunks, current = [], []
    size = lambda xs: sum(len(x.split()) for x in xs)
    for unit in units:
        cost = len(unit.split())
        if cost > budget: raise ValueError('semantic unit exceeds budget')
        if current and size(current) + cost > budget:
            chunks.append(current.copy())
            suffix = []
            for old in reversed(current):
                if size(suffix) + len(old.split()) > overlap: break
                suffix.insert(0, old)
            while suffix and size(suffix) + cost > budget: suffix.pop(0)
            current = suffix
        current.append(unit)
    if current: chunks.append(current)
    return chunks

assert chunk_units(['one two', 'three', 'four five'], 3, 1) == [
    ['one two', 'three'], ['three', 'four five']]
assert chunk_units([], 3) == []
```

Use the target tokenizer when the budget is model tokens. Preserve source offsets and stable document IDs for citations; joining units should preserve original separators. A sentence segmenter can fail on abbreviations and tables, so evaluate retrieval with the actual document formats rather than assuming linguistic boundaries always match useful evidence boundaries.

The overlap is a suffix of complete units, not a fixed number of characters cut from the previous chunk. In the example, the unit `three` is retained because it fits the one-word overlap budget, so evidence near the boundary appears in both chunks. Before appending the next unit, the algorithm may shrink that suffix to respect the overall budget.

The main correctness conditions are preserving unit order, including every original unit, never splitting a unit and ensuring any repetition comes only from deliberate overlap. Test empty input, exact-budget units, zero overlap and a next unit so large that all overlap must be dropped. The repeated `size` calls make this a simple reference implementation rather than an optimal packer; cached unit costs and running totals can avoid repeated scans. Real tokenizers also count separators and metadata, so budget those when joining units. Semantic segmentation remains a separate problem: a sentence boundary is not always a complete explanation or a safe procedural step.
