## Question

What is Attention in machine learning models? What happens in a neural network if you remove all the hidden layers?

## Brief answer

Attention forms a context-dependent weighted combination of value vectors, with weights determined by query/key compatibility. Removing all hidden layers leaves a single affine mapping followed by the output activation, such as linear or logistic regression. Multiple affine layers without nonlinearities also collapse to one affine map, so depth alone does not supply nonlinear expressiveness.

## Detailed answer

Scaled dot-product attention computes $\mathrm{softmax}(QK^T/\sqrt{d_k}+M)V$, where $M$ masks invalid positions. Self-attention draws queries, keys, and values from the same sequence; cross-attention uses a different source for keys and values. Multi-head attention learns multiple projections, allowing different relationships to be represented.

Attention weights are not automatically faithful explanations of a model's decision; downstream transformations and correlated features matter. Likewise, a network with no hidden layer can still classify linearly separable data well, but cannot represent arbitrary nonlinear boundaries in the original input space. Feature engineering can make a linear classifier expressive in transformed features. Attention Is All You Need specifies the standard scaled dot-product formulation.

### Attention computes a contextual mixture

For a query whose scores against two keys are equal, softmax assigns each weight 1/2 and the output is the average of their value vectors. If one score exceeds the other by $\log3$, its weight becomes 3/4. Learned projections decide which similarities matter, while masking prevents access to padding or future tokens. The values carry the information being combined; keys and queries determine the combination.

Removing all hidden layers leaves an affine map followed by the chosen output function. Binary logistic regression can separate points with a linear boundary, but cannot classify XOR in the original two-dimensional coordinates: opposite corners belong to the same class. Adding nonlinear hidden units or an engineered interaction feature makes that pattern representable. Multiple affine layers without intervening nonlinearities also collapse to one affine map. Attention itself is input-dependent because its weights come from softmax over similarities, so it should not be confused with a fixed weighted average or a purely linear layer.
