## Question

What’s the formula of an FFN block with GLU (Gated Linear Unit)?

## Brief answer

A GLU multiplies a linear value branch by a sigmoid gate, and an FFN adds an output projection.

## Detailed answer

With column vectors and hidden width $h$:

$$
\operatorname{FFN}_{\mathrm{GLU}}(x)=W_o\left[(W_vx+b_v)\odot\sigma(W_gx+b_g)\right]+b_o.
$$

$W_v,W_g\in\mathbb R^{h\times d}$ and $W_o\in\mathbb R^{d\times h}$. The gate and value vectors must have the same shape. The elementwise product controls each hidden feature separately; it is not an attention distribution over tokens.

Separate the branches conceptually. The value projection proposes hidden features; the gate projection determines how strongly each is transmitted. If a gate logit is zero, its sigmoid is 0.5, so that value coordinate is halved. A gate logit of 2 yields about 0.881, while -2 yields about 0.119. Different tokens can therefore pass different combinations of features through the same learned matrices.

The gate is not a probability distribution over features: its coordinates do not sum to one. Nor does it decide which source token to attend to. It modulates features within one token, then the output projection combines those gated features back into the model width.

Ignoring biases, the block has $3dh$ parameters, compared with $2dh$ for a conventional FFN at the same hidden width. Reducing $h$ by roughly two thirds matches that projection parameter count, subject to implementation rounding. Sigmoid gates can saturate and yield small gate gradients, so initialization and activation scale matter. Replacing the sigmoid with GELU or SiLU creates a different gated variant, not an equivalent algebraic rearrangement.
