## Question

Compute the KL divergence given different random variables.

## Brief answer

KL divergence compares probability distributions on the same support, not arbitrary lists of sampled values. For discrete distributions, sum `p * log(p/q)`, treating zero-probability terms under p as zero. If p assigns positive mass where q assigns zero, the divergence is infinite. KL is directional and is not a distance metric.

## Detailed answer

```python
import math

def kl(p, q):
    if len(p) != len(q) or not p: raise ValueError('matching nonempty support required')
    if any(not math.isfinite(x) or x < 0 for x in [*p,*q]): raise ValueError('invalid probability')
    if not math.isclose(sum(p),1) or not math.isclose(sum(q),1): raise ValueError('not normalized')
    total = 0.
    for a,b in zip(p,q):
        if a == 0: continue
        if b == 0: return math.inf
        total += a*math.log(a/b)
    return total

assert abs(kl([.5,.5],[.5,.5])) < 1e-12
assert math.isinf(kl([1,0],[0,1]))
assert math.isclose(kl([1,0],[.5,.5]), math.log(2))
```

Natural logarithms give nats; base-two logs give bits. For continuous variables, use densities with respect to the same measure and integrate, or derive a closed form for a known family. A histogram estimate depends on binning and finite-sample bias. Different variable names do not define comparable distributions until support and representation are aligned; do not compute KL directly between raw observations and call it a distributional divergence.

For $p=[0.75,0.25]$ and $q=[0.5,0.5]$, the divergence is $0.75\log(1.5)+0.25\log(0.5)\approx0.1308$ nats. Reversing the arguments gives a different value, about 0.1438 nats. This asymmetry reflects that the expectation is taken under the first distribution: errors in regions where it places more mass matter more.

KL is nonnegative for valid distributions and is zero when they agree almost everywhere under the relevant measure. Individual summands can be negative, so do not clip each term separately. A zero target mass contributes zero by a limit, while positive target mass against zero predicted mass gives infinite divergence.

For sampled data, first define comparable supports or density models. Two lists of observations with different scales or meanings are not probability vectors. Smoothing a histogram avoids infinite estimates but changes the distribution being measured, so disclose that choice. In numerical code, small negative totals from floating-point error may occur near equality, but substantial negatives indicate invalid inputs or a faulty computation.
