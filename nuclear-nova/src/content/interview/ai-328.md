## Question

Divide two integers without using multiplication, division or modulo. Find the number of connected components in a graph. Check balanced parentheses.

## Brief answer

These are three independent problems: use shifted subtraction for signed integer division, graph traversal for connected components, and a stack for balanced delimiters. Specify overflow and graph direction first. The examples below use Python integers, truncation toward zero, an undirected graph, and parentheses/brackets/braces while ignoring other characters.

## Detailed answer

```python
def divide(a, b):
    if b == 0:
        raise ZeroDivisionError
    negative = (a < 0) != (b < 0)
    x, y = abs(a), abs(b)
    quotient = 0
    for shift in range(max(0, x.bit_length() - y.bit_length()), -1, -1):
        if (y << shift) <= x:
            x -= y << shift
            quotient |= 1 << shift
    return -quotient if negative else quotient

def components(n, edges):
    if n < 0:
        raise ValueError("negative vertex count")
    adj = [[] for _ in range(n)]
    for a, b in edges:
        if not (0 <= a < n and 0 <= b < n):
            raise ValueError("invalid vertex")
        adj[a].append(b); adj[b].append(a)
    seen, count = set(), 0
    for start in range(n):
        if start in seen:
            continue
        count += 1
        stack = [start]; seen.add(start)
        while stack:
            for nxt in adj[stack.pop()]:
                if nxt not in seen:
                    seen.add(nxt); stack.append(nxt)
    return count

def balanced(text):
    pairs = {')': '(', ']': '[', '}': '{'}
    stack = []
    for char in text:
        if char in '([{':
            stack.append(char)
        elif char in pairs and (not stack or stack.pop() != pairs[char]):
            return False
    return not stack

assert divide(-17, 3) == -5 and divide(0, 2) == 0
assert divide(2, 7) == 0 and divide(-8, -2) == 4
assert components(4, [(0, 1), (1, 1)]) == 3
assert components(0, []) == 0
assert balanced('a({[]})') and not balanced('([)]')
assert not balanced('(') and balanced('')
```

Division takes $O(\log |a|)$ shift/subtraction steps under a word-operation model; Python big-integer operations themselves scale with bit length. Traversal is $O(V+E)$ time and space. Delimiter checking is $O(n)$ time and up to $O(n)$ stack space. Fixed-width division additionally needs an explicit policy for minimum-integer divided by minus one.

### Why each algorithm works

Division greedily subtracts the largest shifted divisor that fits the remaining magnitude. Each selected shift sets one quotient bit; after processing all shifts, the remainder is smaller than the divisor. The sign is applied once at the end, giving truncation toward zero, so −17 divided by 3 yields −5 rather than Python floor division's −6.

Connected-components traversal starts a search only from an unseen vertex. Every reachable vertex is marked in that search, so each new search corresponds to exactly one component. Isolated vertices count; self-loops and duplicate edges do not add components. The function treats edges as undirected and validates vertex bounds.

Balanced delimiters use last-in-first-out order: the next closing symbol must match the most recent unmatched opener. Counts alone are insufficient because `([)]` contains equal counts but invalid nesting. Non-delimiter characters are intentionally ignored; parsing programming-language strings and comments would require a lexer before this stack check.
