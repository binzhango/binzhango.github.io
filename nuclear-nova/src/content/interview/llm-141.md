## Question

What chunking strategies can you implement with regex, spaCy, or LangChain?

## Brief answer

Chunking strategies include fixed token windows, sentence or paragraph boundaries, recursive separators, document structure, semantic segmentation, and parent-child retrieval.

## Detailed answer

Regex can encode known boundaries; spaCy can identify sentence boundaries; LangChain splitters package token-, character-, or structure-based strategies. These are tools, not inherently different semantic objectives. A character limit is not a token limit. Preserve code blocks, tables, and headings when their structure matters, and test whether overlap or parent expansion improves evidence completeness.

The following runnable standard-library baseline splits paragraphs and then uses overlapping word windows for oversized paragraphs. It is intentionally word-based, not tokenizer-aware; use the model's tokenizer when enforcing an actual token budget.

```python
import re

def chunk_paragraphs(text, max_words=100, overlap=15):
    if max_words <= 0 or not 0 <= overlap < max_words:
        raise ValueError("Require 0 <= overlap < max_words")
    chunks = []
    for paragraph in re.split(r"\n\s*\n", text.strip()):
        words = paragraph.split()
        start = 0
        while start < len(words):
            end = min(start + max_words, len(words))
            chunks.append(" ".join(words[start:end]))
            if end == len(words):
                break
            start = end - overlap
    return chunks

assert chunk_paragraphs("") == []
assert chunk_paragraphs("a b c d e", 3, 1) == ["a b c", "c d e"]
assert chunk_paragraphs("First paragraph.\n\nSecond one.", 3, 0) == [
    "First paragraph.", "Second one."
]
```

The loop advances because overlap is strictly smaller than the window. With fixed overlap ratio, work is linear in input plus emitted text; retaining all chunks uses space proportional to emitted text. Heavy overlap increases both. This baseline normalizes whitespace and does not preserve source offsets, code blocks, or tables, so add those contracts for production ingestion.

A sentence segmenter such as spaCy can improve sentence boundaries, while a recursive splitter tries larger boundaries before smaller ones. Structure-aware splitting is preferable for Markdown headings, functions, or table regions. Regardless of library, evaluate whether retrieved chunks preserve answer qualifications and maintain stable links to their original sources.
