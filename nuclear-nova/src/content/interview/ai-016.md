## Question

Walk me through what happens, tensor by tensor, in one forward pass of a decoder-only transformer.

## Brief answer

Token IDs become embeddings; each decoder block performs normalized causal attention and an MLP with residual additions. A final normalization and vocabulary projection produce logits for next-token prediction.

## Detailed answer

For batch $B$, length $T$ and width $D$, embeddings have shape $[B,T,D]$. Queries reshape to $[B,H_q,T,d_h]$, keys and values to $[B,H_{kv},T,d_h]$. Attention produces per-query-head weighted values, which concatenate and project back to $D$. The MLP expands to an intermediate width, applies its activation or gate, then contracts. Final logits have shape $[B,T,V]$, or only the needed final position during serving. At decode, new keys and values append to cached history; causal offsets must account for that history.

For a small example with $B=2$, $T=5$, $D=16$ and four query heads of width four, the hidden states are $[2,5,16]$ and queries are $[2,4,5,4]$. With two KV heads, keys and values are $[2,2,5,4]$. Each pair of query heads uses one KV head. The conceptual attention scores have shape $[2,4,5,5]$, though a fused kernel need not materialize that tensor. Softmax acts over the final, key-position axis.

After attention, transpose and combine head outputs to $[2,5,16]$, apply the output projection, and add the residual. The normalized MLP branch maps $16\rightarrow H\rightarrow16$, or uses two input branches if gated, then adds another residual. A final vocabulary projection produces one logit per vocabulary item, not a probability until softmax is applied.

In training, logits at position $t$ predict the token at $t+1$; shifting the labels incorrectly can create a deceptively easy copying task. In cached decoding, the new query length is one while key length includes the entire prefix plus the new token. Position IDs and masks must use the absolute history offset. Test full-sequence and cached outputs on the same prefix to catch these shape and masking errors.
