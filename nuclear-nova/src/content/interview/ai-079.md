## Question

Walk me through the OWASP Top 10 for LLM applications and which ones actually bite in practice.

## Brief answer

The OWASP list is a threat-modeling aid covering injection, data exposure, supply-chain and data-poisoning risks, unsafe output use, excessive agency, prompt leakage, retrieval weaknesses, misinformation and resource abuse. Prioritize threats according to the actual tools, data and users in the application.

## Detailed answer

For the 2025 edition, review all ten categories against the system’s trust boundaries. A document assistant especially needs permission-aware retrieval and grounded outputs; an action-taking agent additionally needs constrained authority and idempotent execution. An expensive public endpoint needs token and concurrency budgets. Record attack paths, mitigations and residual risk, then test them rather than claiming checklist completion establishes security.

Using the 2025 taxonomy, examine these ten failure classes in the actual application:

1. Injection: retrieved or user text redirects the legitimate task; constrain authority outside the model.
2. Sensitive disclosure: prompts, outputs or logs expose protected data; minimize access and retention.
3. Supply-chain compromise: dependencies, model artifacts or plugins are untrusted; verify provenance and isolate execution.
4. Poisoning: manipulated training or retrieval data changes behavior; control ingestion and inspect suspicious changes.
5. Unsafe output handling: generated text becomes executable SQL, HTML or commands; validate and sandbox downstream use.
6. Excessive agency: tools grant broader powers than required; scope operations and approvals.
7. Prompt disclosure: internal instructions are exposed; never store secrets or rely on prompt secrecy for authorization.
8. Retrieval/vector weaknesses: access filters, index isolation or embedding assumptions fail; enforce permission boundaries.
9. Misinformation: fluent falsehoods guide decisions; require evidence and calibrated abstention.
10. Resource exhaustion: requests consume unbounded tokens, loops or concurrency; enforce budgets and admission control.

Prioritize by reachable impact. A public summarizer may be most exposed to abusive cost and misleading output; an internal agent with email and database tools has a more consequential exfiltration and action surface. Build one concrete attack path for each relevant category and test the controls at every boundary. The categories overlap, so a single incident may involve poisoned retrieval, injection and excessive tool authority together.
