## Question

Explain the difference between pre-training, supervised fine-tuning and preference optimisation.

## Brief answer

Pretraining learns broad predictive structure from large corpora. Supervised fine-tuning learns desired responses from demonstrations. Preference optimization adjusts behavior using comparisons or rewards rather than only copying a target response.

## Detailed answer

For a chat model, pretraining commonly predicts the next token, SFT masks or emphasizes assistant response tokens, and preference learning favors responses judged better for a prompt. These stages can overlap or repeat. Preference training cannot reliably create knowledge absent from the data, and maximizing a proxy reward can damage useful behavior. Evaluate held-out task quality, safety, calibration and general capabilities after each stage; keep data provenance and contamination checks throughout.

The training signal changes at each stage. In pretraining, the target for a prefix is the next token in a document, so the model learns language, factual associations and many task patterns indirectly. In SFT, a curated instruction and desired response explicitly demonstrate the behavior to imitate. Loss masking can ensure that user and system text provide context without being targets for assistant behavior.

Preference optimization asks a different question: which of two plausible responses is better? A pair may prefer a concise correct answer over a confident invention even if both are fluent. A reward-model-plus-RL pipeline scores newly sampled responses, while a direct preference method learns from ranked pairs. These signals encode evaluator priorities, including their blind spots and inconsistencies.

For a support assistant, pretraining supplies general language ability, SFT teaches the response format and escalation pattern, and preference training can favor grounded, useful resolutions. None replaces a live database for current order status. Excessive SFT on narrow demonstrations can reduce general capability; preference optimization can amplify superficial cues such as verbosity. Hold out prompts, source documents and evaluation rubrics, track changes after each stage, and retain rollback checkpoints so a later improvement in one metric does not conceal a regression elsewhere.
