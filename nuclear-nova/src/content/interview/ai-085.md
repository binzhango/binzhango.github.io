## Question

What is mechanistic interpretability and why do labs invest in it?

## Brief answer

Mechanistic interpretability studies how internal model components implement behavior, using interventions rather than relying only on output correlations. It can help identify circuits, features and failure mechanisms, but current methods do not provide a complete explanation of large models.

## Detailed answer

Inspect activations, perform causal ablations or patching, and test whether a proposed mechanism predicts behavior on new examples. A feature correlated with deception is not proof that it causes deception. Sparse feature methods can improve analysis while introducing their own approximation choices. Labs invest because understanding internal mechanisms may support debugging and safety research. Deployment decisions still require behavioral evaluation and system-level controls.

The aim is to explain computation inside the model at a level that predicts behavior. An analysis might hypothesize that a group of attention heads copies a previous token pattern or that certain features represent a concept. Observing that a neuron activates on examples is a starting correlation; a causal test changes the internal state and checks whether the predicted behavior changes.

Activation patching can replace an internal activation from a corrupted example with one from a clean example and measure whether the correct output returns. Ablation removes or suppresses a component. Both require controls: an intervention can create an unnatural internal state, and a distributed representation may compensate when one component is removed. A compelling mechanism should generalize to new examples and make predictions beyond the cases used to discover it.

Sparse feature methods attempt to separate superposed concepts into more interpretable directions, but their learned features depend on modeling and regularization choices. Large models remain only partially understood, and a plausible circuit diagram is not a complete safety proof. The practical value is better hypotheses for debugging, monitoring and research into undesirable behavior. Combine internal interventions with behavioral tests and system controls; an interpretable explanation is useful when it improves prediction and intervention, not merely when its labels sound intuitive.
