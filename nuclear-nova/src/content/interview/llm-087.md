## Question

How to increase prompt data volume?

## Brief answer

Increase useful data through new source tasks, expert annotation, verified synthetic generation, and carefully chosen transformations.

## Detailed answer

Paraphrases can expand wording diversity, but near-duplicates add little new supervision. Generate from independent source material or target uncovered skills, and verify answers with executable checks, source evidence, or expert review. Track source identity and keep derived examples in the same split. Measure marginal gains as data grows; a larger set of correlated or incorrect outputs can perform worse than a smaller clean dataset.

Think in terms of new learning signal rather than new strings. Rephrasing “summarize this report” fifty ways adds instruction wording diversity but does not add fifty independent report structures. To expand coverage, collect different source documents, introduce distinct constraints, and add cases where the correct action changes, such as insufficient evidence or a contradictory timestamp.

A practical synthetic pipeline chooses a target gap, generates an example and answer from a known source, validates the answer, deduplicates near copies, and records provenance. For code, run tests that check the requested behavior; for numerical answers, independently recompute values; for grounded extraction, verify every important field against the source. Generated data should be rejected when verification is unavailable or ambiguous, rather than trusted because it is fluent.

Keep all descendants of one original example in the same split. Compare learning curves from adding genuinely new sources versus more paraphrases. If quality saturates, inspect error types before generating another large batch. Additional incorrect targets increase confidence in the wrong behavior and can outweigh the benefit of broader wording coverage.
