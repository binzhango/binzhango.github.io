## Question

Design a meeting assistant: recording, diarisation, summary, action items, integrations.

## Brief answer

Build a consent-aware streaming pipeline from recording through transcription and diarization to evidence-linked summaries and action items. Integrations should create drafts or authorized updates with traceable ownership.

## Detailed answer

Keep timestamps through each stage so a summary claim can link to the original segment. Distinguish a proposed action from an agreed commitment and resolve owners explicitly. Handle late transcript corrections by versioning summaries, not silently rewriting sent commitments. Apply meeting access controls to audio, text and derived search indexes. Evaluate factual support, missed decisions, speaker attribution and integration errors alongside latency and transcription quality.

Keep one timeline through recording, ASR, diarization and summarization. Every transcript span carries timestamps and provisional speaker labels; later corrections create a new version. Summaries and action items refer back to those spans so a user can inspect the evidence for a decision or commitment.

Distinguish “we could ship Friday” from “Alex will ship Friday.” The first is a proposal; the second names an owner and date, but still may require confirmation if speaker attribution is uncertain. Represent action items with owner, task, due date, supporting span and confirmation status. Draft integrations into calendars or task systems before consequential writes, and use idempotency keys so reprocessing does not create duplicate tasks.

Handle consent and access at the meeting level and propagate them to recordings, transcripts, summaries and search indexes. A person gaining access to a summary should not automatically gain access to every source recording. If a transcript correction changes a sent commitment, flag it for review rather than silently rewriting history. Evaluate missed decisions, invented actions, owner attribution and integration outcomes, with ASR quality as one contributing metric. A readable summary is not sufficient if it confidently assigns the wrong person a task.
