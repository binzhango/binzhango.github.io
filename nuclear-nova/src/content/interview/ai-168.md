## Question

Explain self-attention. What is its computational complexity, and what are your options when contexts get long?

## Brief answer

Self-attention creates queries, keys and values from the same sequence, then gives each position a weighted mixture of values based on query–key similarity. Dense attention requires quadratic pairwise work in sequence length. Long-context options include memory-efficient exact kernels, sparse attention, recurrent/state-space alternatives, retrieval and reducing the number of retained tokens.

## Detailed answer

For T tokens and head width d, forming attention scores costs $O(T^2d)$ and a naive implementation stores $O(T^2)$ probabilities. Projection and feed-forward costs also matter, especially at shorter sequences. During cached decoding, each new query reads the existing KV prefix rather than recomputing old token states.

FlashAttention-style algorithms reduce memory traffic and intermediate storage while retaining exact dense attention; they do not remove its quadratic arithmetic in full-sequence attention. Sliding windows reduce connections but can lose direct access to distant tokens. Retrieval selects external evidence but changes the task from retaining every token to finding relevant material.

Choose based on target dependencies, latency, memory and quality. Benchmark long-context retrieval and reasoning at multiple positions, not only whether the model accepts a long input. A supported maximum context length does not imply uniform use of every position or unlimited effective recall.


For a fixed width, increasing sequence length from 4,096 to 16,384 multiplies dense pairwise attention work by sixteen, while KV storage grows by four. This contrast explains why a memory-saving kernel can enable a longer context without making its computation cheap. The dense projections and MLP still contribute additional costs proportional to sequence length and model width.

Sliding attention changes the graph of allowed interactions: each position reads only a bounded neighborhood, possibly supplemented by global tokens. Multiple layers can propagate information farther, but that is not equivalent to direct access to every distant token at every layer. Retrieval chooses a subset of external evidence and can miss material before generation begins.

Evaluate the dependencies the application actually needs. Exact copying from a distant position, multi-hop synthesis and broad summarization stress different mechanisms. Compare useful quality per latency and memory budget, and specify whether the proposed optimization preserves the original attention computation or changes the model's available information.
