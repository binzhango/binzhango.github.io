## Question

A lawyer asks about a 200-page credit agreement where the operative clause on page 140 depends on a defined term on page 8. How do you build retrieval that gets this right?

## Brief answer

Retrieve the operative clause and follow explicit definition and cross-reference edges within the same contract version. Preserve page and span provenance for both. Semantic similarity alone may miss a definition 132 pages away, while a generic definition from another agreement can produce a confidently wrong interpretation.

## Detailed answer

**Suggested approach.** Parse sections, defined terms, amendments, schedules, and page coordinates into a document graph. Hybrid retrieval finds the likely clause; graph expansion adds definitions, referenced exceptions, and relevant amendment text within a bounded evidence budget. Resolve duplicate term names using document and section scope, not just the surface word.

Ask the model to explain the relationship using cited spans and distinguish textual extraction from legal judgment. If an essential reference cannot be resolved, flag the missing dependency for reviewer attention. Build evaluation cases where the answer changes when the definition changes, including exceptions and amended terms. Measure complete-evidence recall and unsupported conclusions, not only whether page 140 appeared among search results. The final interpretation remains a reviewable draft for the responsible professional.

### Retrieve the complete reasoning bundle

Represent each clause and defined term as a versioned node, with edges for “defines,” “references,” “amends,” and “excepts.” After finding the page-140 clause, traverse only the edges needed to interpret the query. A visited set prevents cycles, and a budget prevents uncontrolled expansion across an entire agreement. If the required bundle exceeds that budget, report the limitation or switch to a broader review mode rather than silently dropping a decisive definition.

For illustration, the operative clause might permit a transfer only to an “Eligible Assignee.” A definition on page 8 can exclude competitors, and an amendment can add another exception. The correct evidence bundle includes all applicable text. A high similarity score for page 140 alone is therefore not enough to answer whether a particular transfer is allowed.

Store page coordinates and exact source versions so a reviewer can inspect the dependency chain. Test by changing the definition while leaving the operative clause unchanged: the system's conclusion should reflect the changed premise. This is an evidence-completeness test, distinct from evaluating the professional interpretation of that evidence.
