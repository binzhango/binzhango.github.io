## Question

How would you build multimodal retrieval over images, video and text in one index?

## Brief answer

Use compatible multimodal representations or separate modality-specific retrieval paths with calibrated fusion. Store source IDs, timestamps and regions so a retrieved embedding leads back to inspectable evidence.

## Detailed answer

Index image regions/captions, video clips/transcripts and text passages at task-appropriate granularity. A shared embedding space supports cross-modal search but may underperform specialized encoders on OCR or fine visual distinctions. Fuse candidate lists and rerank using the original modalities when affordable. Enforce the same permissions across every representation. Evaluate text-to-image, text-to-video and cross-modal queries separately instead of treating one aggregate recall score as sufficient.

“One index” should mean one query interface and authorization model, not necessarily one undifferentiated vector space. A shared multimodal encoder can align text and image representations for cross-modal retrieval. Specialized OCR, transcript and visual encoders may still add useful candidates for details the shared representation misses.

Ingest each asset with stable IDs and useful units: image regions, timed video clips, transcript spans and text passages. Keep parent relationships so a result can open the relevant crop or time range in the original asset. A query such as “the slide with the red latency chart” may match visual features, while “p99 below 200 ms” may depend on OCR or transcript text.

Retrieve through compatible paths, fuse ranks and rerank a small candidate set using original modalities when affordable. Avoid adding raw scores from unrelated encoders without calibration. Apply permissions to every derived representation and delete them together when the source is removed. Evaluate cross-modal directions separately and include temporal localization, OCR-heavy content and fine-grained visual differences. Track index size, query latency and evidence accuracy; a semantically related clip is not sufficient when the question asks about a specific moment or value.
