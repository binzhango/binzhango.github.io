## Question

Infection-spread simulation.

## Brief answer

Specify the state-transition model before simulating infection: who contacts whom, when exposure occurs, and whether recovery or reinfection exists. Update each time step from a snapshot so newly infected nodes do not immediately infect further nodes in the same step. The original prompt is underspecified; the example uses deterministic spread on a fixed graph with no recovery.

## Detailed answer

```python
def infection_step(graph, infected):
    following = set(infected)
    for node in infected:
        following.update(graph.get(node, ()))
    return following

def simulate(graph, initial, steps):
    if steps < 0: raise ValueError('negative steps')
    states = [set(initial)]
    for _ in range(steps): states.append(infection_step(graph, states[-1]))
    return states

graph = {'a':['b'], 'b':['c'], 'c':[]}
assert simulate(graph, {'a'}, 2) == [{'a'}, {'a','b'}, {'a','b','c'}]
```

Each step costs work proportional to contacts of currently infected nodes. For stochastic spread, inject a seeded random generator and specify whether multiple infectious contacts combine as independent trials. For an SIR model, store susceptible, infected and recovered states separately and define recovery timing.

Test disconnected nodes, cycles, empty populations and simultaneous updates. This toy graph process is an algorithmic exercise, not a validated epidemiological forecast; real forecasting requires calibrated contact and transmission assumptions plus uncertainty analysis.

The snapshot rule determines the meaning of a time step. In the chain `a→b→c`, starting with only `a` infected should reach `b` after one step and `c` after two. Mutating the same set while iterating could allow `b` to infect `c` immediately, accidentally changing the model to an asynchronous cascade.

For probabilistic transmission with independent per-contact probability $p$, a susceptible node exposed to $m$ infected contacts has infection probability $1-(1-p)^m$. That assumption differs from applying one trial regardless of contact count. Recovery introduces another ordering choice: specify whether a node transmits before or after recovering during the current step.

Keep transition rules separate from the loop and inject randomness so tests are reproducible. Check population invariants, such as disjoint susceptible/infected/recovered sets when using SIR, and handle nodes with no adjacency entry. The code is a deterministic graph exercise. Any claim about real disease spread would need calibrated contact data, justified model assumptions and uncertainty analysis beyond this algorithm.
