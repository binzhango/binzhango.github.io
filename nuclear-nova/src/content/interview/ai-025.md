## Question

What are TTFT, TPOT, ITL and throughput, and how do they trade against each other?

## Brief answer

TTFT measures time to first token; ITL measures individual gaps between streamed tokens; TPOT usually averages generation time per output token after the first. Throughput measures completed work per unit time, often output tokens per second.

## Detailed answer

Define whether queueing and network time are included and how aborted requests are counted. A server can increase throughput by batching more requests while worsening TTFT or ITL. Mean TPOT can conceal pauses, so report ITL percentiles and user-level request distributions. Evaluate realistic input/output-length mixtures and arrival patterns. Optimize useful requests meeting their latency objectives, not a single peak token-rate number.

Suppose a request arrives at time zero, receives its first token at 0.8 seconds and its hundredth at 5.75 seconds. Its TTFT is 0.8 seconds and average TPOT after the first token is $(5.75-0.8)/99=0.05$ seconds. That average does not reveal whether every interval was 50 ms or whether one interval paused for a second while others were faster.

Throughput is a fleet or worker aggregate. Ten simultaneous streams at 20 output tokens per second each yield 200 output tokens per second, but every user still sees 20. Batching may raise the aggregate while lowering each stream's rate. Mixing input and output tokens in one throughput number can also mislead because their compute and memory costs differ.

Define measurement boundaries explicitly: service-side timestamps exclude some transport and client delays, whereas client-observed TTFT includes them. Separate queue wait, tokenization, retrieval, prefill and streaming. Report percentiles by prompt length, output length and service tier, plus cancellation and rejection rates. A practical capacity measure is goodput: requests or tokens completed within their latency and quality objectives. It prevents a system from claiming success by accepting more traffic than it can serve usefully.
