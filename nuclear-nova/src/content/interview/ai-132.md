## Question

What are the key components of a Transformer model and why does each matter?

## Brief answer

A Transformer combines token embeddings, positional information, attention, feed-forward layers, residual connections and normalization. Attention exchanges information across positions; the feed-forward network transforms each position's features. A decoder also needs a causal mask and an output projection that produces next-token logits. Encoder–decoder models add cross-attention between the two sequences.

## Detailed answer

Follow one token through the model. Its ID becomes a vector, positional information distinguishes order, and attention computes a content-dependent mixture of other vectors. The feed-forward block expands and contracts the representation, adding nonlinear capacity. Residual paths carry information around each sublayer and improve gradient flow; normalization controls activation scale.

The original Transformer uses an encoder and decoder, whereas many language models use only a causal decoder. Cross-attention reads encoder states; self-attention reads states from the same sequence. The final vocabulary projection and softmax turn the last representation into a probability distribution. Training shifts targets by one token and masks padding from the loss.

Removing position information makes ordinary self-attention permutation-equivariant. Removing causality leaks future targets. Removing normalization/residual structure makes deep optimization much harder. Distinguish these functional roles from optional implementation choices such as tied embeddings and pre-norm.

For “the cat sat,” a decoder's representation of `sat` can combine information from `the` and `cat`, while the representation used to predict `cat` must not read `sat`. The causal mask enforces that training constraint. An encoder used for classification can read both directions because it is not predicting an unseen next token under the same objective.

Attention and the feed-forward block do different work: attention mixes positions dynamically, while the MLP transforms features independently at each position using shared weights. Residual paths let a sublayer add an update instead of reconstructing all useful information from scratch. These roles explain why an efficient attention kernel does not remove the compute cost of the MLP.

When debugging, test the components separately: shapes and masks for attention, scale and finite values for normalization, and shifted labels for the output loss. A model that trains unusually well because future tokens leaked is incorrect even if every matrix multiplication and optimizer step runs successfully.
