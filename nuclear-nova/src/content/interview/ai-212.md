## Question

Serialize and deserialize a binary tree.

## Brief answer

Serialize a binary tree with explicit null markers so shape is unambiguous, then consume the same traversal order during deserialization. Preorder is simple: node, left subtree, right subtree. Values alone are insufficient because different trees can have the same preorder sequence when missing children are not represented.

## Detailed answer

```python
import json
from dataclasses import dataclass

@dataclass
class Node:
    value: int
    left: object = None
    right: object = None

def serialize(root):
    tokens = []
    def visit(node):
        if node is None: tokens.append(None); return
        tokens.append(node.value); visit(node.left); visit(node.right)
    visit(root)
    return json.dumps(tokens)

def deserialize(text):
    tokens = iter(json.loads(text))
    def build():
        try: value = next(tokens)
        except StopIteration: raise ValueError('truncated tree')
        if value is None: return None
        return Node(value, build(), build())
    root = build()
    try: next(tokens)
    except StopIteration: return root
    raise ValueError('trailing tokens')

root = Node(1, None, Node(2))
assert deserialize(serialize(root)) == root
assert deserialize(serialize(None)) is None
```

This contract restricts node values to integers, reserving JSON null for absent children. Validate types and input-size limits when reading untrusted data. Time and output size are O(n); recursion uses O(height) stack and can overflow on a very deep tree, so an iterative decoder is appropriate for adversarial or unbounded depth. Test empty, one-sided and duplicate-value trees.

Null markers distinguish a node with a left child from one with a right child. For root 1 and only right child 2, preorder tokens are `[1, null, 2, null, null]`; omitting nulls would lose the shape. Deserialization consumes exactly the same recursive grammar: one value, then a complete left subtree and a complete right subtree.

A valid binary tree with n nodes produces $2n+1$ tokens including nulls. Rejecting truncated and trailing tokens catches malformed structures, but the sample still needs explicit type validation if untrusted input must obey the stated integer-value contract. JSON parsing alone permits strings, arrays and other values.

The structure is a tree, not a general object graph: cycles or shared references require IDs and a different serialization format. Deep skewed trees can exceed recursion limits despite linear total work, so use an iterative stack for unbounded inputs. Tests should compare both values and structure after round trips and include duplicate values, since identity cannot be reconstructed from value uniqueness assumptions.
