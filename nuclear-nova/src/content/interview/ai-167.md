## Question

How do you handle missing data in Pandas?

## Brief answer

First identify why values are missing, then choose dropping, imputation or an explicit missing category based on the column and task. Use `isna` rather than equality with NaN. Fit imputation statistics on training data only, preserve useful missingness indicators, and check nullable dtypes so cleaning does not silently change representation.

## Detailed answer

```python
import pandas as pd

train = pd.DataFrame({'age':[20., None, 40.], 'city':['A', None, 'B']})
test = pd.DataFrame({'age':[None, 30.], 'city':[None, 'C']})
median_age = train['age'].median()

def clean(frame):
    result = frame.copy()
    result['age_missing'] = result['age'].isna()
    result['age'] = result['age'].fillna(median_age)
    result['city'] = result['city'].fillna('Unknown')
    return result

assert clean(test)['age'].tolist() == [30., 30.]
assert clean(test)['age_missing'].tolist() == [True, False]
```

Dropping rows can bias the sample if missingness is related to the outcome. Forward-fill is only valid when ordering and domain semantics justify carrying the previous value; never fill across unrelated entities. An all-missing training column has no usable median and needs a separate policy. Pandas distinguishes several missing sentinels and nullable dtypes, so test both the values and resulting column types.

The example computes the age median once from training data, then reuses it for test data. Recomputing a median on the full dataset leaks information from evaluation into preprocessing. The separate `age_missing` feature preserves the fact that a value was absent, which can itself carry signal but may also encode a problematic collection process.

Distinguish structural absence, data corruption and unobserved values. A missing apartment number may mean “not applicable,” while a missing income may correlate with the outcome and require a different treatment. Dropping rows changes the sample; filling every numeric column with zero invents a value that may have a real meaning.

Check nullable integer, boolean and categorical dtypes after cleaning, and preserve an explicit policy for all-missing columns or unseen categories. For time-series data, sort within entity before forward filling and avoid using future observations to fill past predictions. Evaluate the entire preprocessing pipeline on held-out data, with missingness rates monitored after deployment so a broken upstream feed does not silently become a model-quality regression.
