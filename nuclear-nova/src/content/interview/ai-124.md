## Question

Given a helper method that crawls a URL, write a crawler over a domain: first synchronous, then make it async.

## Brief answer

Normalize and deduplicate URLs before scheduling them, constrain traversal to the allowed origin, and bound both concurrency and total pages. The async version must claim URLs before awaiting a fetch so multiple workers cannot enqueue the same page. Redirects and DNS resolution must also obey the boundary in the real fetcher.

## Detailed answer

Here the helper returns discovered links. Breadth-first levels make the async implementation simple and deterministic while a semaphore bounds active fetches.

```python
from urllib.parse import urljoin, urlsplit, urldefrag
from collections import deque
import asyncio

def normalize(base, link): return urldefrag(urljoin(base, link))[0]
def origin(url):
    p = urlsplit(url); return p.scheme, p.hostname, p.port

def crawl_sync(seed, fetch, limit=100):
    queue, seen = deque([seed]), {seed}
    while queue:
        url = queue.popleft()
        for link in fetch(url):
            target = normalize(url, link)
            if origin(target) == origin(seed) and target not in seen and len(seen) < limit:
                seen.add(target); queue.append(target)
    return seen

async def crawl_async(seed, fetch, limit=100, concurrency=8):
    if concurrency < 1 or limit < 1: raise ValueError('positive bounds required')
    sem, seen, frontier = asyncio.Semaphore(concurrency), {seed}, [seed]
    async def get(url):
        async with sem:
            try: return await fetch(url)
            except Exception: return []
    while frontier:
        results = await asyncio.gather(*(get(u) for u in frontier))
        following = []
        for url, links in zip(frontier, results):
            for link in links:
                target = normalize(url, link)
                if origin(target) == origin(seed) and target not in seen and len(seen) < limit:
                    seen.add(target); following.append(target)
        frontier = following
    return seen

pages = {'https://example.test/':['/a'], 'https://example.test/a':['/']}
assert len(crawl_sync('https://example.test/', pages.__getitem__)) == 2
```

Honor robots policy and per-host politeness separately from concurrency. Normalize default ports and reject credentials in a production URL policy. Keep query-string rules deliberate: removing queries can collapse distinct pages, while retaining every tracking parameter can explode the crawl.

The `seen` set represents claimed work, not just completed fetches. Claiming before scheduling prevents two parents from discovering the same link and launching duplicate requests. A synchronous queue gives breadth-first traversal; the async version fetches one frontier concurrently, then deterministically constructs the next. The semaphore limits active I/O, while the overall page limit bounds the reachable work retained in memory.

Frontier batching can wait for the slowest page at each level. A worker-queue design can improve utilization but needs careful atomic claiming and termination detection. Neither version should assume a URL's initial hostname guarantees the final destination: redirects and DNS resolution require validation in the fetch adapter to preserve the allowed-origin policy.

Test cycles, relative links, fragments, duplicate links, failed fetches and redirects. Canonicalization must be conservative because query parameters can change content; stripping them indiscriminately loses pages. Define handling for default ports, trailing slashes and credentials. The implementation is a traversal core, so timeouts, response-size limits, robots rules and per-host pacing remain explicit responsibilities of the surrounding crawler.
