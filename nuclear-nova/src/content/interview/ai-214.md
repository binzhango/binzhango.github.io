## Question

Alien dictionary: determine character ordering from a sorted word list.

## Brief answer

Compare adjacent sorted words and add an ordering edge from the first differing character. Then topologically sort the character graph. Reject a longer word that precedes its exact prefix and reject cycles. Include characters with no edges, and specify how to choose among multiple valid orders.

## Detailed answer

```python
import heapq

def alien_order(words):
    graph = {c:set() for word in words for c in word}
    indegree = {c:0 for c in graph}
    for a,b in zip(words, words[1:]):
        for x,y in zip(a,b):
            if x != y:
                if y not in graph[x]: graph[x].add(y); indegree[y] += 1
                break
        else:
            if len(a) > len(b): return None
    ready = [c for c in graph if indegree[c] == 0]; heapq.heapify(ready)
    out = []
    while ready:
        c = heapq.heappop(ready); out.append(c)
        for following in sorted(graph[c]):
            indegree[following] -= 1
            if indegree[following] == 0: heapq.heappush(ready, following)
    return ''.join(out) if len(out) == len(graph) else None

assert alien_order(['wrt','wrf','er','ett','rftt']) == 'wertf'
assert alien_order(['abc','ab']) is None
assert alien_order(['z','x','z']) is None
```

The heap gives a deterministic lexicographically smallest valid ordering under the host character order. Only the first differing pair establishes a constraint; later positions in those words provide no ordering evidence. Edge deduplication prevents incorrectly inflated indegrees. Graph work is O(V+E) apart from heap/sorting costs, plus the adjacent-word comparisons.

Adjacent words suffice because the list is already claimed to be sorted. For `abc` followed by `abd`, only `c<d` is implied; earlier letters are equal, and later letters after the first difference would not affect lexical order. A longer word preceding its exact prefix, such as `abc` before `ab`, is impossible under any character ordering.

Topological sorting repeatedly selects a character with no unmet predecessors. If characters remain but none is ready, the constraints contain a cycle and no valid alphabet exists. Characters with no edges still belong in the result. Deduplicating edges matters because the same ordering evidence can occur several times without creating multiple independent prerequisites.

The min-heap selects the smallest currently valid character under the host's order, yielding a deterministic valid answer among potentially many. That host order is a tie-breaking convention, not evidence about the alien language. Test duplicate words, disconnected characters, prefix conflicts and cycles. Return a distinct invalid result rather than confusing an impossible ordering with a valid empty alphabet.
