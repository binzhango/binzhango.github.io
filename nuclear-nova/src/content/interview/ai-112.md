## Question

Implement top-k, top-p and temperature sampling over a logits vector.

## Brief answer

Temperature rescales logits before softmax; top-k keeps a fixed number of candidates; top-p keeps the smallest probability-ranked prefix whose cumulative mass reaches the threshold. Renormalize after filtering and sample using an explicit random generator. Zero temperature is greedy selection, not division by zero.

## Detailed answer

The following implementation applies top-k first and then top-p to the remaining distribution. Other operation orders are valid but produce different distributions.

```python
import numpy as np

def sample(logits, temperature=1., k=None, p=1., seed=0):
    z = np.asarray(logits, dtype=float)
    if z.ndim != 1 or not len(z) or not np.isfinite(z).all():
        raise ValueError('finite nonempty vector required')
    if temperature < 0 or not 0 < p <= 1 or (k is not None and k < 1):
        raise ValueError('invalid sampling parameters')
    if temperature == 0: return int(z.argmax())
    order = np.argsort(-z, kind='stable')
    if k is not None: order = order[:k]
    scores = (z[order] - z[order].max()) / temperature
    probs = np.exp(scores - scores.max()); probs /= probs.sum()
    n = min(len(probs), np.searchsorted(probs.cumsum(), p) + 1)
    order, probs = order[:n], probs[:n]
    probs /= probs.sum()
    return int(np.random.default_rng(seed).choice(order, p=probs))

assert sample([1, 5, 2], temperature=0) == 1
assert sample([1, 5, 2], k=1) == 1
assert sample([1000, 1001], p=.01) == 1
```

The token that crosses the cumulative threshold must be retained. Sorting costs $O(V\log V)$ for vocabulary size $V$; selection algorithms can reduce top-k work. Tiny temperature increases overflow risk unless logits are shifted before exponentiation; for extreme finite inputs, also guard the division itself.

Filtering changes the distribution before sampling. After top-k selection, the code computes probabilities on that subset; top-p then retains the smallest prefix reaching the requested mass in that already-truncated distribution. Changing the operation order can change which tokens survive, so tests must specify semantics rather than assume every library behaves identically.

The fixed default seed makes each standalone call reproducible, but using that same seed for every token in a generation loop resets the random generator repeatedly. A real decoder should keep one generator per sequence or accept an injected generator whose state advances. Test equal-logit ties, `k` greater than vocabulary size, `p` near zero and one, and temperature zero. Statistical tests over many seeds can compare observed frequencies with the expected filtered distribution. The code rejects nonfinite logits, so an upstream mask represented by negative infinity needs a compatible validation path rather than being passed directly into this teaching function.
