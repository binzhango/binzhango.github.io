## Question

What methods, metrics and frameworks can evaluate retrieval and generation in RAG?

## Brief answer

Evaluate retrieval and generation separately, then measure end-to-end task success with references, human judgments, and carefully calibrated automated judges.

## Detailed answer

Retrieval metrics include recall@k, precision@k, MRR, and nDCG when relevance labels support them. Generation metrics include answer correctness, faithfulness to evidence, citation precision/coverage, and appropriate abstention. A faithful answer can still be factually wrong if its source is wrong.

Ragas provides evaluation metrics, and LangSmith supports dataset-based evaluation and tracing. LLM judges need rubrics, versioning, and calibration against humans; reference-free scores are not ground truth. Include multi-hop, unanswerable, outdated, and adversarial-source cases.

With five relevant documents and three of them in the top ten, recall@10 is $3/5=0.6$ and precision@10 is $3/10=0.3$. Reciprocal rank measures how early the first relevant result appears: if it is third, the query contributes $1/3$ to MRR. nDCG can account for graded relevance and position. These metrics require judgments appropriate to the question; an incomplete label set can wrongly penalize another valid source.

For generation, score the answer's requested content separately from support. Citation precision asks whether cited evidence supports the associated claims; citation coverage asks whether claims needing support have it. An answer can cite a real document yet attribute a claim it never makes. Test abstention with genuinely unanswerable requests, not only easy positive examples.

Automated judges need fixed rubrics, representative calibration against people, and versioned prompts/models. Check disagreement cases and sensitivity to answer length or style. Frameworks organize evaluation but do not supply ground truth automatically. Report stage-level results, overall successful-answer rate, and operating cost so a better retrieval score is not mistaken for a guaranteed better application.
