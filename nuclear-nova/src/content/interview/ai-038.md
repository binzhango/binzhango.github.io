## Question

What causes semantic drift in embedding search and how do you detect it?

## Brief answer

Embedding-search drift occurs when query or document distributions change, or when indexing and querying use incompatible embedding profiles. Similarity then becomes a weaker proxy for relevance even if the service remains operational.

## Detailed answer

Version the model, tokenizer, normalization, dimensions and preprocessing as one embedding profile. Never mix incompatible vectors in the same logical index. Monitor retrieval judgments on stable canaries and fresh production samples, segmented by content age and domain. Inspect nearest neighbors for new terminology or templates. Re-embed into a parallel index, evaluate, and switch atomically rather than partially replacing vectors under live traffic.

Distinguish representation incompatibility from relevance drift. If the query encoder changes but stored document vectors do not, their coordinates may no longer be comparable even if dimensions match. This is a deployment correctness error. If both use the same model but users start asking about new products or a different language, the embedding space remains mathematically compatible while its ranking quality may deteriorate.

Keep a frozen canary set with judged neighbors and a rolling sample of new queries. Track score distributions, empty-result rate and neighborhood overlap, but treat these as alarms rather than proof of quality. A change in average similarity can result from benign traffic mix; an unchanged average can hide failures for a new product family. Human relevance judgments or verified task outcomes are needed to interpret the signal.

When migrating encoders, dual-build the new index from the same document revisions, run both systems on identical queries and compare relevant-result recall by slice. Ensure preprocessing, normalization and distance metric are paired with the model. Switch the query encoder and index pointer atomically, retain a rollback index, and continue observing fresh production traffic. Re-embedding everything without diagnosing stale documents, chunking or permission filters can incur substantial cost while leaving the real defect intact.
