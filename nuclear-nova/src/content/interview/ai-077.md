## Question

How would you evaluate an agent, as opposed to a single model response?

## Brief answer

Evaluate agents on end-to-end outcomes, action correctness, recovery and resource use, not only final answer quality. The execution trace matters because a correct-looking response can conceal an unauthorized or failed action.

## Detailed answer

Build sandbox tasks with known initial and target states. Check tool arguments, authorization boundaries, idempotency, cancellation and recovery from injected failures. Score success under realistic step, time and cost budgets. Include long-horizon tasks and adversarial tool outputs. Separate planning failures from execution failures, and manually inspect cases where the agent reports success but the environment state disagrees.

An agent should be evaluated against the environment state it was supposed to change. In a sandbox booking task, start with known availability and permissions, then check that exactly the intended reservation exists. The final answer can be polished and still falsely claim success, duplicate a booking or modify the wrong account.

Design task fixtures with initial state, allowed operations, success predicates and resource budgets. Inject transient failures, invalid tool responses, ambiguous user requests and malicious retrieved text. Test whether the agent retries safely, asks for needed information, respects cancellation and preserves a recoverable checkpoint. Long-horizon tasks should include changes in instructions and partial progress, since a short successful demo does not establish persistence.

Score final task success, prohibited actions, intermediate state damage, recovery quality and cost. Distinguish a model choosing a wrong action from a tool failing to execute a correct one; fixes differ. Use repeated runs for stochastic policies and report variance. Compare with a simpler fixed workflow or single model call when possible. A more autonomous loop is justified by better outcomes under realistic budgets, not by the number of steps or tools it can invoke.
