## Question

What’s the difference between prefix decoder, causal decoder, and encoder-decoder architectures?

## Brief answer

A causal decoder uses causal self-attention; a prefix decoder adds bidirectional attention within a designated prefix; an encoder-decoder uses a separate encoder and decoder connected by cross-attention.

## Detailed answer

For translation, a causal decoder generates French tokens while attending to all preceding prompt and output tokens. It does not lose access to the English prompt. A prefix LM lets the English prefix tokens contextualize one another bidirectionally, while output tokens attend to the prefix and preceding outputs. An encoder-decoder encodes the source bidirectionally, then a causal decoder cross-attends to those representations. The distinction is the attention connectivity, not merely the wording of the prompt.

Use a four-position example with source tokens $s_1,s_2$ and target tokens $t_1,t_2$. In a causal decoder, the representation of $s_1$ cannot see $s_2$, while the representation used to predict a target can see the preceding source and target tokens. In a prefix decoder, both source representations can see both source tokens; target representations retain causal restrictions. In an encoder-decoder, the source has its own bidirectional stack and the target stack reads it through separate cross-attention projections.

This affects where work is performed. An encoder-decoder computes the source representation once and can cache its cross-attention keys and values. A causal decoder caches the prompt's keys and values in the same stream used for generated tokens. Both can generate incrementally; a prefix decoder requires the whole bidirectional prefix before computing its representations correctly.

Choose architecture and objective together. Translation naturally separates source and target, while general continuation naturally fits a single stream. Merely labeling a prompt “source” does not change an already-trained causal model into a prefix-attention architecture.
