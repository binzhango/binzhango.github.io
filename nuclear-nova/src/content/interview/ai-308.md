## Question

Design cross-lingual RAG: the knowledge base is in English and Hindi, but users ask in Tamil, Telugu or transliterated Hinglish.

## Brief answer

Suggested approach: use multilingual retrieval with explicit language and script handling, retrieve authorized English and Hindi evidence, and generate an answer in the user's requested language with citations. Add translated-query retrieval as a complementary channel. Code-mixed and transliterated queries need their own evaluation slices, not forced conversion into a single language.

## Detailed answer

Normalize Unicode and identify likely languages without discarding the original query. Generate optional script-normalized or translated variants, then combine multilingual dense retrieval with lexical retrieval for names, identifiers, and exact terms. Rerank candidates using the original question and retain document language, version, permissions, and provenance.

Ground the answer in retrieved passages; translate evidence meaning carefully and preserve numbers, eligibility conditions, and proper nouns. If translation or retrieval confidence is inadequate, ask a targeted clarification or route to a fluent human. Test native questions from Tamil, Telugu, Hindi, English, and Hinglish speakers, including misspellings and different transliteration conventions. Measure evidence recall separately from answer correctness so a fluent translation cannot hide retrieval failures.

### Follow a code-mixed query

A user might ask in Tamil about an English-named government scheme, with a district written in Latin characters. Preserve the original text, create a normalized transliteration variant where reliable, and retrieve through both multilingual embeddings and lexical matches for the scheme and district. Merge candidates by source identity, then rerank against the original intent so a translation error does not silently become the query.

The answer generator receives approved evidence with its language and effective date. It answers in the user's requested language while preserving numbers and eligibility qualifiers. If two documents disagree, prefer the applicable authoritative version or surface the conflict; translating both fluently does not resolve it. Build evaluation pairs containing the question, expected evidence IDs, and required factual fields. Retrieval recall diagnoses missing evidence, while entity-preservation and answer review diagnose translation or generation. Cache by language, normalized intent, permissions, and source version rather than treating all translations as interchangeable.
