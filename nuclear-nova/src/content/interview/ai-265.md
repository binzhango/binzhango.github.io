## Question

DeepSeek-V3 uses auxiliary-loss-free load balancing. What was wrong with the auxiliary loss, and how does the bias trick work?

## Brief answer

An auxiliary balancing loss can interfere with the main learning objective if weighted too strongly. DeepSeek-V3 instead adjusts per-expert routing biases according to observed load, encouraging underused experts without adding that balancing signal to the main router gradient.

## Detailed answer

In the V3 report, section 2.1.2, top-k selection uses affinity plus bias, while output gating uses the original affinity. Overloaded experts receive a lower bias and underloaded experts a higher one. “Auxiliary-loss-free” is not the absence of every auxiliary term: V3 also retains a small sequence-wise balancing loss. When implementing an analogous controller, check update timescale and load measurement; delayed feedback can oscillate, while aggressive balancing can send tokens to poor experts. Compare quality, dropped work and per-expert latency rather than only an evenly populated routing histogram.

### The bias is a feedback controller

For each token, compute expert affinities and select top-k using affinity plus an expert-specific bias. Compute output combination weights from the original affinities so the balancing offset does not directly become semantic output weight. After observing load, lower biases for overloaded experts and raise them for underused ones. The adjustment uses detached utilization statistics rather than adding the main balancing force to the task gradient.

An auxiliary loss instead contributes a gradient encouraging balance; if its coefficient is too large, it can distort the router's task-driven specialization. The bias controller avoids that particular gradient interference but creates its own control problem. Measurements over too few tokens are noisy, slow feedback can lag distribution shifts, and aggressive updates can oscillate. Track selected assignments and capacity overflow at the appropriate distributed scope. Compare both quality and tail latency, since perfectly equal counts are not the only goal. Retaining a small sequence-wise auxiliary term means the V3 label should not be interpreted as literally zero auxiliary objectives anywhere.
