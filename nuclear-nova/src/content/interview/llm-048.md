## Question

Which models use MQA or GQA?

## Brief answer

PaLM uses MQA; Llama 2 70B and Mistral 7B use GQA. Llama 2 7B and 13B use MHA.

## Detailed answer

These version-specific examples show why a family name alone is insufficient. Check the ratio between query-head and KV-head counts in the checkpoint configuration; equal counts indicate MHA, one KV head indicates MQA, and an intermediate count indicates GQA. Some models use other compressed attention designs that should not be classified solely by this rule.

Read `num_attention_heads`, `num_key_value_heads`, and the head dimension in the specific checkpoint configuration. For an ordinary attention implementation, 32 query heads with 32 KV heads indicate MHA; 32 with eight indicate GQA; 32 with one indicate MQA. Some implementations omit a separate KV field when it defaults to the query-head count, so inspect the implementation rather than interpreting a missing field as one.

The choice affects deployment planning. A model with more total parameters can still use less KV memory per token than another model if it has fewer layers, KV heads, or smaller head dimensions. Weight-memory and cache-memory comparisons must therefore be performed separately.

The named examples are historical checkpoint designs, not statements about every later family member. A quantized checkpoint usually retains the attention grouping while changing numerical representation, but converted models may alter other details. Compressed-latent or hybrid recurrent architectures need their own state-size calculation; forcing them into a simple MHA/GQA/MQA label can hide the actual memory layout. Verify tensor shapes and supported serving kernels before using a family name to estimate capacity.
