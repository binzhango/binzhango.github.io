## Question

Implement scaled dot-product attention with a causal mask, from scratch, in NumPy or PyTorch.

## Brief answer

Compute query–key scores, divide by the square root of the head dimension, mask future positions before softmax, and use the probabilities to average values. Subtract each row's maximum for numerical stability. A causal mask must use absolute query positions during cached decoding; a square lower-triangular mask only covers full-sequence attention.

## Detailed answer

This NumPy reference takes one head, with query shape `(T, d)` and matching key/value sequence lengths. `offset` is the absolute position of the first query. It rejects fully masked rows instead of silently producing NaNs.

```python
import numpy as np

def attention(q, k, v, offset=0):
    q, k, v = map(lambda x: np.asarray(x, dtype=float), (q, k, v))
    if q.ndim != 2 or k.ndim != 2 or v.ndim != 2:
        raise ValueError('expected matrices')
    if q.shape[1] != k.shape[1] or len(k) != len(v) or not len(k):
        raise ValueError('incompatible shapes')
    scores = q @ k.T / np.sqrt(q.shape[1])
    allowed = np.arange(len(k))[None, :] <= (offset + np.arange(len(q)))[:, None]
    if not allowed.any(axis=1).all():
        raise ValueError('fully masked query')
    scores = np.where(allowed, scores, -np.inf)
    weights = np.exp(scores - scores.max(axis=-1, keepdims=True))
    weights /= weights.sum(axis=-1, keepdims=True)
    return weights @ v

q = np.ones((3, 2))
v = np.arange(3)[:, None]
assert np.allclose(attention(q, q, v).ravel(), [0, .5, 1])
assert np.allclose(attention(q[-1:], q, v, offset=2), [[1]])
```

For query length $T$, key length $S$, key width $d_k$ and value width $d_v$, time is $O(TS(d_k+d_v))$; score storage is $O(TS)$. This is commonly abbreviated to $O(TSd)$ when both widths scale as $d$. Padding masks need to be combined with causality. Production fused kernels avoid materializing the full matrix.

The first assertion exposes the causal behavior directly. Because every query/key dot product is equal, the first position can read only value 0, the second averages values 0 and 1, and the third averages 0, 1 and 2. Their outputs are therefore 0, 0.5 and 1. The cached query uses absolute offset 2 so it sees all three keys; using offset zero would incorrectly restrict it to the first key.

The matrix multiplication contracts the feature dimension, while softmax normalizes across key positions. Confusing those axes can produce plausible-shaped but incorrect output. Extend testing with unequal query/key lengths, nontrivial values and padding, comparing against a trusted reference. The implementation assumes positive head width and ordinary finite inputs; production validation should reject zero-width, nonfinite and malformed shapes before numerical operations. The reference intentionally materializes scores so correctness is inspectable, while a tiled kernel is needed when quadratic score storage becomes prohibitive.
