## Question

In NumPy, compute minADE and minFDE for multi-modal trajectory predictions with variable-length ground truth. No Python loops.

## Brief answer

Compute Euclidean error for each batch, mode, and timestep; mask invalid timesteps; average each mode over valid ground truth for ADE; and gather each mode's final valid error for FDE. Minimize across modes separately. Reject empty trajectories, and state whether valid timestamps must form a contiguous prefix.

## Detailed answer

This NumPy implementation supports an arbitrary boolean validity mask and returns per-example metrics. It avoids Python loops. The mode minimizing ADE need not minimize FDE, so this is the independent-minimum definition; some benchmarks use an FDE-selected mode for both and must be implemented differently.

```python
import numpy as np

def min_errors(pred, truth, valid):
    # pred [B, K, T, D], truth [B, T, D], valid [B, T]
    pred, truth = np.asarray(pred, float), np.asarray(truth, float)
    valid = np.asarray(valid, bool)
    if pred.ndim != 4 or truth.shape != (pred.shape[0], pred.shape[2], pred.shape[3]):
        raise ValueError('shape mismatch')
    if valid.shape != truth.shape[:2] or pred.shape[1] == 0 or pred.shape[2] == 0:
        raise ValueError('empty modes/time or invalid mask')
    counts = valid.sum(axis=1)
    if np.any(counts == 0):
        raise ValueError('empty ground-truth trajectory')
    delta = np.where(valid[:, None, :, None], pred - truth[:, None], 0.0)
    error = np.linalg.norm(delta, axis=-1)
    if not np.isfinite(error).all():
        raise ValueError('nonfinite valid coordinates')
    ade = error.sum(axis=2) / counts[:, None]
    last = np.max(np.where(valid, np.arange(valid.shape[1]), -1), axis=1)
    fde = error[np.arange(pred.shape[0])[:, None], np.arange(pred.shape[1])[None, :], last[:, None]]
    return ade.min(axis=1), fde.min(axis=1)

pred = np.array([[[[0, 0], [2, 0], [99, 0]], [[1, 0], [1, 0], [99, 0]]]])
truth = np.zeros((1, 3, 2))
a, f = min_errors(pred, truth, [[True, True, False]])
assert np.allclose(a, [1]) and np.allclose(f, [1])
```

Time is O(BKTD), with O(BKTD) temporary storage. Test unequal lengths, non-prefix masks, one valid point, padded NaNs, and different best modes. Best-of-K metrics do not evaluate probability calibration and can improve merely by predicting more modes.

### Verify the masking and the meaning of each minimum

For one example with valid timesteps at positions zero and one, suppose mode A has distances `[0, 2]` and mode B has `[1, 1]`. Both have ADE 1, but their FDE values are 2 and 1, so minADE and minFDE are both 1. The padded third timestep in the code example contributes nothing even though its predicted coordinate is large.

For a non-prefix mask such as `[True, False, True]`, the final valid point is index two, not `valid_count - 1`. The `max(where(...))` expression handles that case. Masking coordinate differences before taking the norm also prevents padded NaNs from contaminating the sum, while the finite-value check rejects nonfinite coordinates at valid timesteps.

Independent minima can select different modes. If mode A has errors `[0, 4]` and mode B `[3, 3]`, minADE is 2 from A while minFDE is 3 from B. A benchmark that selects the best final-displacement mode first would report ADE 3 instead. State the convention before comparing results.

Broadcasting creates the full batch-by-mode-by-time-by-coordinate difference array, so memory can dominate for large K or long horizons. Production evaluation can process batches in chunks while retaining vectorized operations within each chunk. Keep units and sampling intervals consistent, and fix K across comparisons so extra hypotheses do not create a misleading best-of-K improvement.
