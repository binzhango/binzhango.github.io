## Question

Walk me through a post-training recipe to turn a pretrained base model into a personalised assistant.

## Brief answer

Start with task demonstrations and preference data for general assistant behavior, then add permission-scoped personalization through retrieval or explicit preferences. Do not train one shared model indiscriminately on private user histories.

## Detailed answer

Define what personalization means: tone, saved preferences, relevant memories or task competence. SFT can teach interaction conventions; preference optimization can improve judged usefulness after a stable baseline. Keep user-specific facts in a versioned memory layer when deletion, freshness and attribution matter. Filter training data by provenance and authorization, split evaluations by user and time, and test general capabilities alongside personalized tasks. Prevent memories from one account entering another account's context. Compare against prompting and retrieval before adding per-user adapters, which introduce storage, routing and update costs. Evaluate whether personalization is helpful, accurate and easy for the user to correct or disable.

### Separate shared behavior from personal facts

Begin with a pretrained checkpoint and a representative assistant evaluation set. Supervised fine-tuning teaches instruction following, tool formats, refusal boundaries, and conversational conventions. Preference optimization can then improve qualities that demonstrations alone do not capture, using comparisons with a consistent rubric and an independent holdout. Check retained reasoning, language coverage, and factuality after each stage.

Personalization can usually happen at inference through explicit preferences and retrieved memories. For “prefer concise replies” or “use my saved dietary restrictions,” attach account-scoped, dated facts with a way to inspect, correct, and delete them. Do not infer a permanent preference from one ambiguous conversation. A memory write needs a policy for consent, sensitivity, expiration, and conflict resolution. Per-user adapters are another option but complicate storage, routing, deletion, and evaluation. Compare with the simpler memory baseline first. Test cross-account isolation and stale or contradictory preferences. Success means the assistant helps the particular user without fabricating memories or degrading general capabilities.
