## Question

Why use label smoothing, and how is its modified loss derived?

## Brief answer

Label smoothing replaces one-hot targets with a mixture of the target and a prior, discouraging overconfidence. It is useful in some settings but is not universal in LLM training.

## Detailed answer

For vocabulary size $V$, one-hot target $y$, and a uniform prior:

$$
q_k=(1-\epsilon)y_k+\frac{\epsilon}{V},\qquad
L=-\sum_kq_k\log p_k
=-(1-\epsilon)\log p_y-\frac{\epsilon}{V}\sum_k\log p_k.
$$

The correct class receives $1-\epsilon+\epsilon/V$. An alternative convention assigns $1-\epsilon$ to the correct class and $\epsilon/(V-1)$ to each other class; do not mix the two definitions. Benefits depend on the task and smoothing strength, and the smoothed training loss is not ordinary hard-target perplexity.

For three classes, target class 1, and $\epsilon=0.1$, the uniform-mixture convention gives target probabilities approximately $(0.9333,0.0333,0.0333)$. The logit gradient becomes $p-q$ instead of $p-y$. A prediction of probability exactly one for class 1 would heavily penalize the nonzero target mass assigned to the other classes, so the optimum no longer requires infinite separation of the winning logit.

This can discourage overconfident fitting to hard labels, especially when annotations are imperfect. It also deliberately introduces bias: an example whose correct class is certain is trained as if there were uncertainty. Too much smoothing weakens the learning signal, and a uniform prior over a large vocabulary is not a model of which alternative words are semantically plausible.

When reporting perplexity, recompute ordinary NLL against the observed tokens rather than exponentiating the smoothed objective. If comparing distillation or calibration behavior, examine it directly; improved classification accuracy does not prove improved confidence calibration. Document the convention because the two common definitions produce different target distributions at the same numeric epsilon.
