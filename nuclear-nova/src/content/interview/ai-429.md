## Question

A user loads a 2 TB dataset with `datasets` on a 64 GB RAM machine and it works. How? And when does it stop working?

## Brief answer

The dataset need not be fully resident in RAM. Arrow-backed datasets can memory-map local files so the operating system pages in accessed regions, while streaming datasets read and process examples incrementally. These are different modes: memory mapping still requires suitable local storage, and streaming changes random-access, shuffling, and transformation capabilities.

## Detailed answer

A 2 TB disk-backed dataset can work with 64 GB RAM when operations touch bounded batches. It fails when code materializes the whole dataset as Python objects, uses enormous batches or shuffle buffers, caches excessive decoded media, or launches too many workers. Compressed input expansion and temporary transform outputs also require disk and memory planning.

For streaming, use shard-aware iteration, bounded buffers, and reproducible worker partitioning. Global exact shuffle and arbitrary indexing are not free. For mapped data, random access can create page-fault-heavy I/O and poor throughput even without an out-of-memory error. Measure resident memory, disk usage, read patterns, and data-loader queues.

### Virtual address space is not resident RAM

An Arrow-backed dataset can map files into virtual memory and load pages as accessed. Iterating bounded batches therefore need not keep 2 TB resident at once. Operating-system caching may use available RAM, but reclaimable mapped pages differ from materializing millions of Python dictionaries. Streaming is another mode: it reads and decodes examples incrementally, often without a complete local cache.

A transform can still break the budget by converting the full dataset to pandas, retaining outputs in a list, or spawning workers with large prefetch queues. Media decoding can expand compact files dramatically. Map operations may also require temporary disk space comparable to transformed data. Streaming shuffle uses a finite buffer and is not a uniform permutation of an arbitrary infinite stream; exact random access has different requirements. Estimate sample size after decoding, batch size, worker count, and prefetch depth together. Measure both peak resident memory and I/O throughput, because a dataset that fits can still train slowly through random page faults.
