## Question

What is LangChain?

## Brief answer

LangChain is a framework and integration ecosystem for building applications and agents around language models.

## Detailed answer

It provides abstractions for models, messages, tools, prompts, retrieval, and structured outputs. Current LangChain agents use LangGraph for execution and persistence. The framework coordinates application logic; it does not make the underlying model more accurate automatically. Use it where its integrations and orchestration simplify the application, and check the documentation matching the installed version.

Think of an application as a sequence of typed operations: accept messages, choose or format a model request, call tools, retrieve evidence, and interpret the result. LangChain provides common interfaces and integrations for many of these operations so application code need not implement every provider adapter itself. A model remains the component generating text or action requests; the framework manages the surrounding process.

For example, a document assistant can combine a retriever, a prompt, a chat model, and a structured answer type. A more open-ended assistant may let the model choose whether to search or calculate, while application code validates and executes that choice. The deterministic pipeline and model-directed loop have different failure modes even if they use the same components.

Use the framework when its abstractions reduce integration work and make execution inspectable. A direct API call may be simpler for a single fixed operation. Current APIs differ from older chain-and-memory tutorials, so pin the implementation version and test the actual behavior. Framework adoption does not establish grounding, authorization, reliable retries, or answer correctness; those remain application responsibilities.
