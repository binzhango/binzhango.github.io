## Question

Why can a model become less capable after SFT?

## Brief answer

SFT can degrade apparent capability through overfitting, forgetting, low-quality targets, overly aggressive updates, or incorrect chat formatting.

## Detailed answer

Check the inference template, stop tokens, tokenizer, label masking, and generation settings before blaming the objective. Compare base and tuned checkpoints on both the target task and general regression tests. Repetitive or erroneous demonstrations can teach shortcuts; excessive steps or learning rates can overwrite useful behavior. Improve data and mixtures, reduce update strength, and choose checkpoints by held-out utility rather than training loss alone.

Classify the regression before changing hyperparameters. If answers contain broken role markers or never stop, inspect the chat template and special tokens. If formatting improves but factual performance drops, compare training targets and task mixtures. If the model becomes narrowly repetitive, check duplicates and excessive training duration. These causes need different fixes.

A low SFT loss only means the model predicts the supplied demonstrations well. If demonstrations routinely invent missing values or ignore context, the objective rewards those habits. If every example belongs to one narrow workflow, updates can shift behavior away from tasks that were not represented. Full tuning gives broad freedom to change parameters, while PEFT restricts the update but does not guarantee absence of regressions.

Evaluate base, intermediate, and final checkpoints using identical generation settings on both target and retained-capability suites. Include paraphrases and unfamiliar inputs to distinguish learning the procedure from memorizing answers. Improve or rebalance data, reduce update strength, or select an earlier checkpoint according to that evidence. Keep the original checkpoint so rollback is possible, and test the exported serving artifact rather than only the training model object.
