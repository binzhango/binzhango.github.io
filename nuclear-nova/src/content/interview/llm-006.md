## Question

How can you distinguish between model parameters and hyperparameters?

## Brief answer

Parameters are learned model values; hyperparameters configure the model or learning process.

## Detailed answer

Weights, biases, and learned embeddings are parameters. Learning rate, weight decay, layer count, and batch size are hyperparameters. Hyperparameters can be selected by a search algorithm and can change during training, as with a learning-rate schedule; they are not necessarily fixed manually before every run. Validation data guides their selection, while test data remains reserved for final evaluation.

In a linear predictor $\hat y=wx+b$, the fitted slope $w$ and intercept $b$ are parameters. The learning rate determines how far an optimizer moves them at each step; the regularization strength determines how expensive large weights are. Those are hyperparameters because they govern the procedure rather than being the resulting fitted coefficients.

For example, train three candidate models with different regularization strengths on the same training split. Select the strength using validation error, then report the chosen system's performance on an untouched test set. Repeatedly changing the strength after observing test results would turn that test set into another development set.

The distinction is about role, not whether a human typed the value. Automated search can choose learning rates, while a learned temperature can be a model parameter when optimized within the model's objective. Architecture choices such as layer count also become part of the saved model configuration. Reproducibility requires preserving both the learned weights and the configuration, tokenizer, preprocessing, and selection procedure that produced them.
