## Question

How to construct instruction fine-tuning datasets?

## Brief answer

Build instruction-response examples from real target tasks, with correct outputs, representative coverage, and leakage-safe splits.

## Detailed answer

Define the expected behavior and annotation rubric first. Include realistic context, multi-turn interactions, difficult cases, tool results where appropriate, and examples where evidence is insufficient. Deduplicate by source or intent before splitting; paraphrases of the same example should not straddle training and evaluation. Record provenance and applicable data permissions. Synthetic examples need verification and should fill identified coverage gaps rather than merely inflate row counts.

Begin with a task specification that says what information the model receives and what a correct response must contain. For a maintenance-report assistant, each example should include the actual report, the requested transformation, and an answer whose statements are supported by that report. Include absent fields, conflicting observations, and requests requiring clarification so the model learns what to do beyond ideal inputs.

Split by originating document or case before creating paraphrases and synthetic variants. Otherwise, an answer derived from one source can appear in both training and evaluation under different wording. Store source identity, annotation rubric, and review status. Check both semantic correctness and serialization: valid tool-call arguments, expected role order, end-of-turn tokens, and which response tokens receive loss.

Measure coverage across task type, difficulty, length, language, and uncertainty. Synthetic generation is useful for filling identified gaps, but a second model repeating the same unsupported claim is not independent verification. Prefer executable checks for code and calculations, source comparison for factual extraction, and expert review where domain judgment is needed. A smaller consistent dataset can teach a more reliable procedure than a large collection of plausible but inconsistent answers.
