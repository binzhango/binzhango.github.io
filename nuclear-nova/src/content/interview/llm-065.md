## Question

Write the cross-entropy loss and explain its meaning.

## Brief answer

Cross-entropy is $H(p,q)=-\sum_kp_k\log q_k$; it penalizes assigning low predicted probability to target outcomes.

## Detailed answer

For a one-hot target class $y$, the loss reduces to $-\log q_y$. Language modeling applies this over vocabulary predictions and averages over supervised token positions. For soft targets, such as a teacher distribution or label smoothing, every target probability contributes. Define the reduction and masking explicitly: averaging per example and averaging per token can weight variable-length sequences differently.

For a target distribution $p=(0.75,0.25)$ and a prediction $q=(0.5,0.5)$, cross-entropy is $-0.75\log0.5-0.25\log0.5=\log2\approx0.693$ nats. The minimum for fixed $p$ occurs at $q=p$, where the loss equals the target entropy, about 0.562 nats. It is therefore not generally true that a perfect match has zero cross-entropy; that happens for a deterministic one-hot target in the limiting perfect prediction.

With logits followed by softmax, the gradient is $q-p$. The model is pushed to raise classes whose predicted probability is below their target mass and lower those whose prediction is too high. For hard labels, only one target probability is one; for distillation, the teacher distributes mass among alternatives.

For language modeling, decide whether to average over all tokens or average each sequence first. A 1,000-token response receives more weight than a ten-token response under token averaging. Padding and excluded prompt positions must contribute neither loss nor denominator count. This bookkeeping affects optimization as much as the formula itself.
