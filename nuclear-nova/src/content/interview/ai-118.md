## Question

Implement cosine similarity search over embeddings, then explain why you would not ship it.

## Brief answer

Normalize document and query vectors, then rank their dot products. This exact baseline is valuable for validating recall and may be sufficient for small corpora. At large scale, a full scan becomes limited by memory bandwidth and latency; production also needs permission filtering, updates, durability and an evaluated approximate index.

## Detailed answer

```python
import numpy as np

def cosine_search(vectors, query, k):
    x, q = np.asarray(vectors, float), np.asarray(query, float)
    if x.ndim != 2 or q.shape != (x.shape[1],) or k < 0:
        raise ValueError('invalid shapes or k')
    norms, qnorm = np.linalg.norm(x, axis=1), np.linalg.norm(q)
    if not np.isfinite(x).all() or not np.isfinite(q).all() or qnorm == 0 or (norms == 0).any():
        raise ValueError('finite nonzero vectors required')
    scores = (x @ q) / (norms*qnorm)
    ids = np.argsort(-scores, kind='stable')[:k]
    return [(int(i), float(scores[i])) for i in ids]

assert cosine_search([[1,0], [0,1], [-1,0]], [2,0], 1) == [(0, 1.)]
```

The scan costs $O(Nd)$ and sorting $O(N\log N)$; partitioning can reduce selection to expected $O(N)$. A million 768-dimensional float32 vectors alone consume about 3.07 GB before metadata and index overhead. Benchmark approximate retrieval against this exact result, with representative tenant filters. Do not reject brute force automatically: a small authorized corpus on a GPU can be simpler and faster than operating a distributed ANN service.

Cosine similarity divides the dot product by both vector norms, making direction rather than magnitude determine the score. The query `[2,0]` therefore matches `[1,0]` with similarity one even though their lengths differ. Zero vectors have no direction and are rejected; nonfinite entries would make ranking unreliable and are rejected too.

If document vectors are normalized once during ingestion and the query is normalized once per request, ranking reduces to a matrix-vector product. Preserve the same embedding model, preprocessing and metric for both sides. Stable sorting gives deterministic tie order in this reference, while approximate indexes may need a separate tie policy.

Use this implementation as an oracle for small test corpora when tuning an ANN index. Compare approximate top-k overlap and application relevance separately. A production wrapper must enforce tenant filters before returning candidates, track document versions and handle updates and deletions. Brute force can be the right implementation for a small authorized subset; the reason to replace it is a measured scaling or operational need, not the word “production” alone.
