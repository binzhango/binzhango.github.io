## Question

Would detecting spam emails be treated as a supervised or unsupervised learning problem, and why?

## Brief answer

Spam detection is usually supervised binary classification because training messages have spam/not-spam labels.

## Detailed answer

The model learns a decision function from those examples and predicts labels or probabilities for new messages. In practice, semi-supervised learning can use unlabeled email, and anomaly detection can help find new campaigns. Evaluate precision and recall under realistic class imbalance; a high overall accuracy can hide costly false positives.

A labeled training row consists of the email representation and a target, for example `spam = 1`. The model can learn $P(\mathrm{spam}\mid x)$; an application then compares that score with a threshold. Moving the threshold upward generally catches fewer spam messages but reduces accidental blocking of legitimate messages. The threshold is a product decision distinct from learning the probability model.

Suppose a test set contains 990 legitimate messages and 10 spam messages. A system that always predicts legitimate achieves 99% accuracy while detecting no spam. If another system flags 12 messages, of which 8 are spam, precision is $8/12\approx67\%$ and recall is $8/10=80\%$. Those numbers make the tradeoff visible.

Build the holdout from a later time period and group duplicate campaigns to avoid an inflated score. User reports provide useful labels but are incomplete and selection-biased. Unsupervised clustering can discover a new campaign for investigation, yet assigning the spam decision still requires a definition of undesirable mail and appropriate validation.
