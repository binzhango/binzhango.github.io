## Question

The onboard compute budget is fixed. Walk me through quantizing and pruning a vision model without losing recall on small objects.

## Brief answer

Suggested approach: Profile the deployed model first, then quantize or structurally prune components that produce real hardware savings while protecting small-object features. Small objects are especially sensitive to reduced resolution, aggressive downsampling, and low-precision feature loss. Optimize under an explicit recall and latency budget, not just a smaller parameter count.

## Detailed answer

Use representative calibration data enriched with distant, occluded, low-light, and rare objects. Compare layer sensitivity and retain higher precision in fragile operators or detection heads. QAT or distillation can recover some accuracy after quantization. Prefer structured pruning that the target runtime can exploit; arbitrary zero weights may not accelerate dense kernels.

Measure recall by object size and distance, localization error, false positives, and the downstream planner's behavior. Validate sustained latency, memory bandwidth, and thermal constraints on the actual onboard hardware. Keep a held-out scenario suite and compare each optimization independently. If recall loss exceeds the accepted bound, adjust architecture or scheduling instead of hiding the loss in an aggregate mAP score.

### Optimize the sensitive parts selectively

Small objects occupy few pixels and may have low-magnitude features. Aggressive activation clipping or reduced feature-map resolution can erase them while leaving large-object mAP nearly unchanged. Profile layer sensitivity using the same small-object and low-light slices after each proposed quantization or pruning change.

Structured channel pruning reduces tensor dimensions and can accelerate supported dense kernels, but removing channels changes downstream shapes and usually needs retraining. Unstructured zeros do not guarantee a speedup unless the hardware and runtime exploit that sparsity pattern. Quantization-aware training exposes the model to simulated low-bit error, while distillation can preserve a stronger teacher's outputs. Retain higher precision or resolution in fragile stages if necessary. Benchmark the complete perception pipeline, including preprocessing and postprocessing, under sustained temperature and worst-case scene density. Accept a change only when its actual latency/energy savings justify any bounded loss in the required recall and localization metrics.
