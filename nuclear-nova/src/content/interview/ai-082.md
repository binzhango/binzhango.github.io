## Question

What is Constitutional AI and how does it differ from RLHF? What is RLAIF?

## Brief answer

Constitutional AI uses explicit principles to guide model critique, revision and preference feedback. RLAIF uses AI-generated feedback in reinforcement learning; the concepts overlap but are not interchangeable.

## Detailed answer

A constitutional workflow can revise supervised responses against principles and use model-generated preference comparisons for later optimization. This reduces some dependence on human labels while making the chosen principles more explicit. It does not remove human choices about values, rubric interpretation, data or evaluation. Judge errors and blind spots can be amplified. Compare harmfulness and helpfulness on independent tests, not only agreement with the same judge.

The “constitution” is a set of written principles used to guide feedback. In a supervised phase, a model can critique an initial response against a principle and revise it; the revised responses become training targets. In a preference phase, a model can compare candidate responses using those principles, providing preference labels that support further optimization.

This differs from a standard human-preference pipeline primarily in how some feedback is generated and structured, not in eliminating human choices. People still choose the principles, prompts, data, evaluation criteria and how conflicts between principles are resolved. RLAIF is broader: it describes reinforcement learning using AI feedback, whether or not that feedback comes from an explicit constitution.

For example, a principle might encourage honesty about uncertainty. A critique can identify an unsupported factual assertion and revise it into a bounded answer. But if the critic lacks the relevant evidence, it may confidently endorse the same error. Shared blind spots can therefore propagate through both generation and evaluation. Compare helpfulness, harmfulness and factuality on independent tests and review cases where principles conflict. Making values explicit improves inspectability of the training process; it does not make the learned behavior a formally verified implementation of those values.
