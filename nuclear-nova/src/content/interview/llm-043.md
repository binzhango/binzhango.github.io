## Question

What are the attention variants?

## Brief answer

Attention variants differ in connectivity, head sharing, position treatment, mathematical formulation, and implementation.

## Detailed answer

Self-attention versus cross-attention identifies where queries and keys/values originate. Causal, local, and block-sparse masks define connectivity. MHA, GQA, and MQA define KV sharing. Relative biases and RoPE encode position. Linear attention changes the attention formulation; FlashAttention is an efficient algorithm for supported attention operations. These categories overlap: a causal GQA layer with rotary embeddings can run using a FlashAttention kernel.

A concrete layer can be described along several axes simultaneously: causal self-attention, 32 query heads, 8 KV heads, rotary position encoding, and an optimized fused execution kernel. “Causal” says which positions are accessible; “self” says where tensors originate; GQA says how keys and values are shared; rotary encoding says how positions affect matching. None of these labels substitutes for the others.

For a translation decoder, its self-attention may be causal GQA while a separate cross-attention layer reads all valid encoder positions. A sliding-window mask can be added to restrict self-attention to nearby tokens. Linear attention instead changes the aggregation formula and maintained state, so it is not simply another mask or implementation backend.

When asked to compare variants, choose the axis relevant to the question and state its consequence. Head sharing primarily changes cache size and K/V representation capacity; connectivity changes accessible evidence; execution kernels change how the operation uses hardware. This classification avoids claims such as “FlashAttention replaces cross-attention” or “all sparse attention is hard attention,” which conflate independent design choices.
