## Question

Your chat agent is moving to the phone. What actually changes?

## Brief answer

Phone interaction adds streaming speech recognition, speech synthesis, turn detection, interruptions, telephony failures, and a much tighter conversational latency budget. Errors become harder to inspect and correct than text, so confirmation of names, numbers, and consequential actions needs deliberate design. Reuse the business-policy layer while redesigning the interaction loop.

## Detailed answer

**Suggested approach.** Maintain partial and final transcript states, speaker turns, and audio timestamps. Start planning on stable partial speech where safe, but defer writes until the user's intent and required confirmation are final. Support barge-in by stopping playback and canceling obsolete generation. A hangup must cancel unnecessary work without losing transaction reconciliation.

Design pronunciation, digit grouping, silence recovery, and transfer to a human. Provide alternatives for poor audio or accessibility needs. Measure end-of-speech to first-audio latency, interruption recovery, task completion, entity errors, and repeated questions. Test accents, background noise, packet loss, voicemail, and a user interrupting a confirmation. A fast first token is not a fast spoken response if endpointing or the speech synthesizer still buffers a full sentence.

### Audio introduces a second streaming state machine

The system must track what the user has said, what the recognizer currently hypothesizes, what text has been generated, and what audio has actually been played. These are not the same state. If the user interrupts midway through a spoken sentence, the next model turn should not assume the unheard remainder was communicated.

For example, a caller says “cancel my flight—actually, only the return leg.” Acting on an unstable partial transcript can execute the wrong operation. Plan or prefetch while speech is arriving, but bind consequential actions to the finalized intent and confirmation. Barge-in stops playback, cancels obsolete generation, and preserves any already committed backend operation for reconciliation.

Budget endpoint detection, ASR stabilization, model response, TTS startup, transport, and the playback buffer. Optimize time to meaningful first audio without speaking unfinished or misleading fragments. Phone numbers, dates, prices, and booking codes need deliberate spoken formatting and confirmation. Test an interrupted confirmation, a dropped call after submission, and recovery by a human with the same transaction state; these expose failures that a text-only transcript benchmark will miss.
