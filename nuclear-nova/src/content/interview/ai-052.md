## Question

What makes an agent loop terminate correctly? How do you bound cost and steps?

## Brief answer

An agent should terminate when its explicit success condition is verified, when it cannot make useful progress, or when a resource limit is reached. A model emitting “done” is not sufficient proof of completion.

## Detailed answer

Track step count, elapsed time, token/tool cost and repeated-state fingerprints outside the model. Validate success against observable artifacts or application state. Detect repeated failing actions and require a changed strategy before another attempt. Distinguish completed, partial, blocked and canceled results in the final response. Budget exhaustion must preserve a recovery checkpoint and accurately report unfinished work rather than declaring success.

Define completion as an observable predicate before starting. “Create a draft report with these five sections” can be checked against a saved artifact; “book the appointment” requires confirmation from the scheduling system. The model's final message is a report about completion, not the source of truth for it.

Maintain counters for model calls, tool calls, tokens, elapsed time and monetary budget. Count retries too. Detect repeated states such as the same failing tool arguments or unchanged search results, and require new information before repeating them. A hard limit prevents runaway loops; a progress test can stop earlier when additional steps are unlikely to help.

For an agent fixing a bug, a successful termination might require a reproduced failure, a change and a passing focused test. If dependencies are unavailable, the appropriate state is blocked or partial with a checkpoint, not successful. Cancellation should propagate to running tools, and finalization should flush the action ledger so resumption does not repeat writes. Test normal success, irrecoverable errors, budget exhaustion and user cancellation. Distinct terminal states make the system honest and resumable, whereas a single `done` flag hides whether the requested outcome was actually achieved.
