## Question

Regular expression matching with '.' and '\*'.

## Brief answer

Use dynamic programming over prefixes or suffixes of the string and pattern. A normal character or dot consumes one character; `x*` either consumes zero copies and skips the pair or consumes one matching character and stays on that pair. Memoization prevents exponential re-exploration of the same states.

## Detailed answer

```python
from functools import lru_cache

def regex_match(text, pattern):
    if pattern.startswith('*') or '**' in pattern: raise ValueError('invalid pattern')
    @lru_cache(None)
    def match(i,j):
        if j == len(pattern): return i == len(text)
        first = i < len(text) and pattern[j] in (text[i], '.')
        if j+1 < len(pattern) and pattern[j+1] == '*':
            return match(i,j+2) or (first and match(i+1,j))
        return first and match(i+1,j+1)
    return match(0,0)

assert regex_match('aab','c*a*b')
assert regex_match('', 'a*')
assert not regex_match('ab','.*c')
assert regex_match('ab','.*')
```

This matches the entire string and supports only literal characters, dot and star; it is not a complete regular-expression engine. There are at most `(len(text)+1)*(len(pattern)+1)` states, giving O(nm) time and memo space. Recursive depth can grow with input length, so use an iterative table for large untrusted inputs. Test zero repetitions, repeated stars as invalid syntax and patterns that match an empty string.

The state `(i,j)` means whether the text suffix from i matches the pattern suffix from j. For `x*`, the zero-occurrence branch advances past both pattern symbols without consuming text. The one-or-more branch consumes one matching character but leaves j in place, allowing another repetition. Memoization ensures each suffix pair is solved once.

For `aab` against `c*a*b`, skip `c*`, consume two `a` characters through the repeated branch, then match `b`. Empty text can match patterns composed entirely of zero-copy starred groups. A plain `.` consumes exactly one code point, while `.*` can consume any number through the same recurrence.

The function implements full-string matching with a deliberately small syntax, not search, captures, escapes or character classes. Validate that contract before comparing with a general regex engine. Test trailing unmatched text, zero repetitions, invalid leading stars and long adversarial inputs. An iterative dynamic-programming table avoids recursion depth limits while retaining the same $O(nm)$ state bound.
