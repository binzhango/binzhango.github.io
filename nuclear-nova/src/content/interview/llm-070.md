## Question

How to compute softmax and cross-entropy loss (and binary cross-entropy)?

## Brief answer

Use softmax plus categorical cross-entropy for mutually exclusive classes, and sigmoid plus binary cross-entropy for independent binary labels; compute both directly from logits for stability.

## Detailed answer

For logits $z$, softmax is $p_k=e^{z_k}/\sum_je^{z_j}$ and categorical CE is $-\log p_y$. Binary CE is $-[y\log\sigma(z)+(1-y)\log(1-\sigma(z))]$.

```python
import torch
from torch.nn import functional as F

logits = torch.tensor([[2.0, 0.0, -1.0]])
ce = F.cross_entropy(logits, torch.tensor([0]))
bce = F.binary_cross_entropy_with_logits(
    torch.tensor([2.0, -1.0]), torch.tensor([1.0, 0.0])
)
print(round(ce.item(), 4), round(bce.item(), 4))  # 0.1698 0.2201
```

Do not pass already-softmaxed probabilities to `cross_entropy` or already-sigmoided probabilities to `binary_cross_entropy_with_logits`. Multi-label tasks apply binary losses per label.

The categorical example has unnormalized exponentials approximately $(7.389,1,0.368)$ and total 8.757, giving the correct class probability about 0.8438. Its loss is $-\log0.8438\approx0.1698$. For the binary examples, the positive target at logit 2 contributes about 0.1269, and the negative target at logit -1 contributes about 0.3133. Their mean is 0.2201, matching the printed output.

The modeling choice matters. A news article assigned exactly one category can use a softmax across categories. An image containing both a dog and a bicycle needs independent labels and usually a sigmoid/BCE for each label. Softmax would force those labels to compete for a total probability of one, which is inappropriate if both can be present.

Loss functions accepting logits combine activation and logarithms stably. Passing probabilities into them applies the transformation again and changes the objective. Check target dtype and shape, specify any class or positive-label weights, and handle masks explicitly. Weighting changes the effective objective and often requires recalibrating the decision threshold; it is not merely a way to improve the printed loss.
