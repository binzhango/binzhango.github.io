## Question

Write a Python function that displays the first n Fibonacci numbers.

## Brief answer

Generate Fibonacci numbers iteratively with two running values. State the convention: the first terms are 0, 1, 1, 2, 3. Producing the first n terms takes n iterations and avoids the repeated work of naive recursion. Reject negative counts and decide whether the function returns values or prints them.

## Detailed answer

```python
def fibonacci(n):
    if type(n) is not int or n < 0: raise ValueError('nonnegative integer n required')
    result, a, b = [], 0, 1
    for _ in range(n):
        result.append(a)
        a, b = b, a+b
    return result

def display_fibonacci(n):
    print(*fibonacci(n))

assert fibonacci(0) == []
assert fibonacci(1) == [0]
assert fibonacci(7) == [0,1,1,2,3,5,8]
```

Returning the sequence makes it easier to test and lets presentation choose formatting. Storing all results costs O(n) values; a generator uses constant auxiliary state. Arithmetic is not truly constant-time for arbitrarily large n because Fibonacci integers gain O(n) bits. If only the nth value is needed, fast doubling is a different problem with logarithmically many big-integer operations.

The loop invariant is that `a` is the next number to emit and `b` is the following one. Simultaneous assignment computes both new values from the old pair, so `a, b = b, a+b` advances one step without overwriting information needed for the sum. Starting at `(0,1)` makes the stated sequence convention explicit.

For `n=3`, the successive emitted values are 0, 1 and 1; the state then becomes `(2,3)`. Test zero, one, two and negative inputs, and reject booleans if the contract requires an integer count rather than Python's integer subclass behavior. The explicit type check does so here.

A naive recursive implementation repeatedly recomputes the same prefixes and is inappropriate for printing all first n values. Iteration shares that work naturally. If output can be streamed, yield or print each value as it is generated to avoid retaining the list, while preserving a pure sequence function when testability and reuse matter.
