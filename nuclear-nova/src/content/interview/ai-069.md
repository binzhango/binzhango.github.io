## Question

How do you build an eval set when there is no labelled ground truth and experts are expensive?

## Brief answer

Start with a small expert-labeled set that represents important decisions and failures, then expand using active sampling and cheaper judgments. Lack of one reference answer does not prevent a well-defined quality rubric.

## Detailed answer

Sample production-like tasks, separate acceptable outcomes from stylistic preferences, and have experts annotate evidence and failure severity. Double-label a subset to measure ambiguity. Use weak labels or a calibrated judge to prioritize uncertain cases, but retain a human audit sample. Keep a sealed release set distinct from development examples. Track confidence intervals and coverage; a large automatically labeled set can be less informative than a smaller trustworthy one.

Start by defining what a successful outcome requires even when no single reference sentence exists. For an enterprise answer, an expert can mark necessary facts, acceptable uncertainty, forbidden disclosures and evidence sources. For a writing task, the rubric can specify audience, constraints and factual accuracy while allowing many valid phrasings.

Select an initial sample by task frequency and consequence, then deliberately add rare but costly failures. Ask experts to annotate the reasoning behind difficult labels so future reviewers can apply the rubric consistently. Double-label a subset and resolve disagreements; low agreement may mean the question or rubric is ambiguous rather than that one reviewer is careless.

Use cheaper methods to expand coverage: executable checks for structured outputs, weak labels from trusted systems, and a calibrated model judge for triage. Active sampling can prioritize cases where models disagree or confidence is low, but retain a random production sample to estimate real failure rates without selection bias. Synthetic cases help explore boundaries but should not replace real tasks. Keep development and release sets separate, version every revision and report uncertainty. A small expert-reviewed set with meaningful slices is more useful than a large set whose labels merely repeat the current model's assumptions.
