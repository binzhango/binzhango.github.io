## Question

What’s the difference between KL divergence and cross-entropy?

## Brief answer

Cross-entropy includes the target distribution's entropy; KL divergence measures the excess beyond it: $H(p,q)=H(p)+D_{\mathrm{KL}}(p\Vert q)$.

## Detailed answer

If $p$ is fixed, minimizing cross-entropy over $q$ is equivalent to minimizing forward KL because $H(p)$ is constant. If the target distribution also depends on optimized parameters, that argument no longer automatically applies. Cross-entropy need not be zero even when $p=q$; KL is zero in that case. Both depend on the chosen direction and log base.

Expand KL algebraically:

$$
D_{\mathrm{KL}}(p\Vert q)=\sum_kp_k\log p_k-\sum_kp_k\log q_k=-H(p)+H(p,q).
$$

The first term depends only on the target distribution. For fixed targets, gradients with respect to the predicted distribution are therefore identical whether optimizing cross-entropy or forward KL. This is why distillation implementations can express closely related objectives using either formulation, provided reduction, direction, and temperature are consistent.

For $p=q=(0.5,0.5)$, cross-entropy is $\log2\approx0.693$ nats while KL is zero. Cross-entropy includes the irreducible uncertainty of the target; KL isolates mismatch. For a one-hot target, the entropy term vanishes and the two values agree.

The equivalence does not justify swapping arguments: $D_{\mathrm{KL}}(q\Vert p)$ is a different objective, and can be infinite against a one-hot target when $q$ assigns any mass elsewhere. Nor can one ignore $H(p)$ when learning the target distribution itself. Check the library's expected input order and whether it expects probabilities or log probabilities; API naming does not always mirror the mathematical notation.
