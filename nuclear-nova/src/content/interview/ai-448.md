## Question

An enterprise wants a document-Q&A assistant over 2M internal documents, pilot in four weeks, and their security team forbids data leaving their VPC. Scope and design it.

## Brief answer

Limit the four-week pilot to a permission-aware, cited assistant for a few high-value document classes inside the customer's VPC. Run parsing, embedding, retrieval, inference, and telemetry within that boundary. Define coverage and answer-quality targets before ingestion; two million documents are an indexing scope, not proof that every document must be ready on day one.

## Detailed answer

**Suggested approach.** Week one establishes threat model, document/ACL inventory, representative evaluation queries, and approved model hardware. Week two builds incremental connectors, stable document IDs, parsing, hybrid retrieval, and permission filtering. Week three adds reranking, cited answers, abstention, and a narrow user pilot. Week four fixes measured errors, load-tests, and rehearses rollback and deletion propagation.

Use a local model whose license and accelerator footprint fit the environment. Disable external telemetry and uncontrolled package/model downloads. Track coverage, extraction failures, ACL freshness, retrieval recall, supported-answer rate, and p95 latency. Cache only within appropriate permission scopes. Explicitly exclude autonomous writes, broad workflow automation, and promises of complete historical coverage until the pilot establishes feasibility. A security review and operational owner are delivery dependencies, not last-day paperwork.

### The concrete in-VPC data path

Connector workers write immutable source versions and ACL snapshots into customer-controlled storage. Parsers emit chunks with document IDs, page or section offsets, and inherited permissions. Local embedding workers populate the vector index alongside a lexical index. At query time, an authenticated identity produces a permission filter, retrieval returns eligible passages, a reranker selects evidence, and the local generator produces an answer whose support can be opened in the original document.

If two million documents average ten chunks, the pilot's eventual index has twenty million vectors. At 768 dimensions and two bytes per component, vectors alone occupy about 30.7 GB in decimal units before search structures, text, replicas, and metadata. This is an illustrative sizing input, not a full memory estimate. Parsing and source API quotas may dominate the four-week schedule more than vector storage.

Make revocation an explicit freshness contract. A user removed from a project must lose access through retrieval, caches, and source previews. For the pilot, prefer a narrower, fully permission-tested corpus over nominal ingestion of every document with uncertain extraction or ACL correctness.
