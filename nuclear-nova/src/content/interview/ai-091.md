## Question

Design barge-in / interruption handling for a voice agent.

## Brief answer

Barge-in requires detecting new user speech while the assistant is speaking, canceling obsolete generation and audio playback, and reconciling what the user actually heard with conversation state.

## Detailed answer

Use acoustic echo cancellation so the assistant’s own audio is not mistaken for an interruption. Tag generated text/audio with turn IDs and cancel both upstream computation and queued playback when a genuine interruption starts. Discard late packets from canceled turns. Record the played portion separately from the full generated reply so the next response does not assume unheard information was delivered. Test overlapping speakers, short acknowledgments and noisy environments.

Use an explicit turn state machine: listening, responding, interrupted and canceled. Each generated text segment and audio packet carries a turn or generation ID. When new user speech is confirmed, stop playback immediately, cancel pending synthesis and generation, and reject any late packets with the obsolete ID. Otherwise a race can cause canceled speech to resume after the new turn begins.

Echo cancellation uses the assistant's playback signal to help distinguish its own audio from incoming speech. Voice activity alone is insufficient in a loud room. Short backchannels such as “uh-huh” may not intend a full interruption, so the policy can distinguish them from sustained speech, but should remain responsive when the user is clearly taking the floor.

Maintain a playback cursor and record only the portion the user likely heard. If the system generated “The first step is X; the second is Y” but playback stopped before Y, future context should not assume Y was communicated. Tool actions already executed are separate from spoken output and may not be cancelable. Test races between interruption, action completion, TTS buffering and packet arrival. Evaluate stop latency, false interruptions and conversation recovery, not just whether the audio eventually becomes silent.
