## Question

What are the core concepts in LangChain?

## Brief answer

Core concepts include models, messages, prompts, tools, retrieval, structured outputs, and execution state; workflows can be deterministic or model-directed.

## Detailed answer

A deterministic workflow specifies the next operation in code. An agent lets the model choose among permitted actions within a controlled loop. LangGraph supplies explicit stateful orchestration, while LangSmith supports tracing and evaluation. Older tutorials also organize concepts around “chains,” “indexes,” and “memory”; retain the concepts without assuming their historical classes remain the preferred APIs.

Follow one request through the concepts. Messages represent the conversation with roles and tool relationships. A prompt combines instructions, the user's request, and selected context. A model returns either a response or a request to invoke a tool. A tool has a schema describing accepted arguments and executable code that performs the operation. State records what has happened and what the next step needs.

Retrieval is one possible operation in that flow: it returns source records that can become context. Structured output constrains the shape expected by the application. Observability records inputs, outputs, timing, and errors so a failed answer can be traced to retrieval, model generation, parsing, or tool execution.

A deterministic workflow chooses the next step in application logic; an agent delegates some action selection to the model. Both need explicit failure handling. For example, a timeout should not leave the system pretending it received a valid result. Persisting state enables resumption, but side effects still need idempotency or confirmation rules where relevant. Keeping these responsibilities distinct makes the system easier to test than treating the framework as one opaque “agent” operation.
