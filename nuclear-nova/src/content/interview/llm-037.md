## Question

What’s the formula of a GLU block using GeLU?

## Brief answer

GEGLU replaces the sigmoid gate in a GLU with GELU.

## Detailed answer

A bias-free column-vector form is:

$$
\operatorname{FFN}_{\mathrm{GEGLU}}(x)=W_o\left[\operatorname{GELU}(W_gx)\odot(W_vx)\right].
$$

Both input projections have shape $h\times d$, and the output projection has shape $d\times h$. Unlike a sigmoid gate, the GELU branch is not bounded between 0 and 1. This block has three projection matrices, so comparisons with an ordinary two-projection FFN should account for hidden width and parameter count.

GEGLU has two learned views of the same input. One becomes a smooth nonlinear gate; the other remains a linear value branch. For a gate preactivation of 1 and a value of 2, the product is approximately $0.8413\times2=1.6826$. With gate preactivation -1, the same value produces approximately -0.3174. Thus the gate can attenuate, change sign, or amplify features rather than merely admit a fraction between zero and one.

This multiplicative interaction increases expressiveness within the FFN. The output projection then mixes gated features and restores the residual width. The operation still acts independently at each token position; it does not replace attention's communication across positions.

For a conventional hidden width of $4d$, a two-matrix FFN has about $8d^2$ parameters. A three-matrix GEGLU block achieves the same count at $h\approx8d/3$. Actual models round widths for hardware alignment and may use biases. A comparison that keeps the same hidden width silently gives GEGLU more parameters, so report the architecture budget when interpreting a quality difference.
