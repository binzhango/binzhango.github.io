## Question

How do you deploy a capable assistant on cost-sensitive or on-device hardware without a datacentre GPU? Walk through the efficiency toolkit.

## Brief answer

Start from the smallest model that meets the task's quality target, then combine quantization, efficient kernels, bounded context, and task-specific adaptation. Use device accelerators when supported and route difficult requests to a server only under an explicit privacy and availability policy. A nominally small weight file is not sufficient: peak memory, sustained power, and thermal behavior determine feasibility.

## Detailed answer

Budget weights, KV cache, activations, scratch space, tokenizer, and application memory. Profile cold startup, prompt prefill, steady decode, and battery drain separately. Quantize with representative calibration data and verify rare or safety-critical outputs; use mixed precision for sensitive layers if necessary.

Reduce unnecessary prompt tokens, cache stable prefixes, cap output length, and distill long workflows into smaller task models when possible. Avoid swapping weights repeatedly from storage, which may destroy interactivity. Test the oldest supported device, long sessions, low battery, and background memory pressure. Expose graceful fallbacks such as a smaller context, deferred processing, or a clear unsupported-operation response rather than silently producing worse results.

### Fit before optimizing speed

For a 3B model, four-bit weight payload is approximately 1.5 GB, but scales, embeddings, runtime buffers, and cache make total memory larger. A device advertising several gigabytes of RAM may expose much less to one application. First select a model and context budget that fit without swapping, then benchmark the supported execution backend.

Quantization reduces weight traffic; distillation reduces the model's required computation; pruning helps only when the runtime exploits its resulting structure. These are different mechanisms and their gains should not be multiplied blindly. A task-specific extraction assistant may work with a small model plus deterministic validation, whereas open-ended reasoning may require a server fallback. Keep tokenization and preprocessing from blocking the user interface, stop generation immediately when canceled, and measure joules per completed task under sustained thermal conditions. The best configuration is the one that remains usable on the least capable supported device.
