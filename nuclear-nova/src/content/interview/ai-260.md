## Question

Design an agent that automates an enterprise workflow, such as drafting RFP responses from internal documents and a CRM. What does enterprise-grade operation add?

## Brief answer

Build an RFP assistant around authorized evidence retrieval, structured drafting and explicit human review before external submission. Enterprise reliability adds identity, permission enforcement, data freshness, auditability, integration recovery and operational ownership.

## Detailed answer

Map each requested statement to approved source material or a clearly labeled gap. Read CRM records through the user's permissions, preserving document versions and citations. Validate prices, commitments and legal/security claims through authoritative systems or reviewers instead of letting the model invent them. Write drafts with idempotent integration calls and keep an action ledger for retries. Test stale permissions, conflicting documents, missing evidence and malicious instructions inside attachments. Measure supported-claim rate, reviewer correction effort and turnaround time. Define who resolves incidents and updates the knowledge base; these responsibilities matter as much as the model prompt.

### Draft claims through an evidence and approval path

Parse the RFP into requirements and requested response fields. Retrieve approved policy and product evidence under the user's permissions, read CRM context through constrained tools, and draft each claim with a traceable source or explicit gap. Commitments such as delivery dates, pricing, security certifications, and contract terms need authoritative validation rather than plausible completion.

Store a versioned draft and review state, separating edits from final external submission. If a source changes or permissions are revoked, revalidate affected claims before approval. Integration writes use idempotency keys and an action ledger so retries cannot create duplicate opportunities or documents. Test conflicting policies, missing evidence, malicious attachment text, stale CRM state, and timeout after a successful write. Measure reviewer correction time and supported-claim rate alongside turnaround. An enterprise agent also needs an owner for source updates, incidents, and model changes; a reliable demo without those responsibilities is not a maintainable operational workflow.
