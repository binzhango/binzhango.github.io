## Question

Write a function to compute root-mean-square error given y_pred and y_true lists.

## Brief answer

RMSE is the square root of the mean squared difference between paired predictions and targets. Validate equal nonzero lengths and finite numeric values. Its units match the target, while squaring gives large errors greater influence. Do not silently truncate mismatched lists with `zip` or report zero for an empty dataset.

## Detailed answer

```python
import math

def rmse(y_pred, y_true):
    if not y_pred or len(y_pred) != len(y_true):
        raise ValueError('matching nonempty lists required')
    if any(not math.isfinite(v) for v in [*y_pred,*y_true]):
        raise ValueError('finite values required')
    errors = [a-b for a,b in zip(y_pred,y_true)]
    return math.hypot(*errors) / math.sqrt(len(errors))

assert rmse([1,2,3],[1,2,3]) == 0
assert math.isclose(rmse([0,2],[0,0]), math.sqrt(2))
```

`hypot` avoids overflow from naively squaring many large finite errors, although subtracting extreme opposite-sign floats can itself overflow. For streaming datasets, use a numerically stable running sum or a scaled sum-of-squares algorithm. Compare RMSE with MAE when outliers matter, and aggregate by the intended unit: averaging per-group RMSE is not the same as computing RMSE over all observations.

For errors `[0,2]`, mean squared error is $(0^2+2^2)/2=2$, so RMSE is $\sqrt2$. If the target is measured in minutes, RMSE is also in minutes. A single large error contributes quadratically, which is appropriate when large misses are disproportionately costly but can obscure typical-case performance.

Computing a global RMSE requires pooling squared errors and counts before taking the square root. Averaging per-group RMSE gives each group equal weight unless explicitly reweighted and is generally a different metric. Report both if the application cares about overall volume and equal treatment of groups.

The implementation stores all errors, so it uses $O(n)$ memory despite linear work. A streaming scaled sum-of-squares accumulator can reduce auxiliary memory. Validate equal lengths before `zip`, and define handling for missing or infinite values rather than silently dropping them. Compare RMSE with MAE and percentile absolute error to understand whether a model's apparent improvement comes from ordinary predictions or only a few extreme cases.
