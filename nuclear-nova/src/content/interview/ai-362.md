## Question

Implement the block manager for a paged KV cache: allocate, append, free, and copy-on-write prefix sharing.

## Brief answer

Represent each sequence as a list of fixed-capacity block IDs, with a reference count per physical block. Sharing a prefix increments counts; appending to a shared partial block first copies it. Full shared blocks remain immutable. Allocation failure must leave existing sequences valid, and production reuse must wait for GPU operations that still reference a block.

## Detailed answer

This runnable CPU reference models token payloads rather than tensors. It is single-threaded and supports whole-sequence prefix forks.

```python
class BlockManager:
    def __init__(self, blocks, block_size):
        if blocks < 1 or block_size < 1:
            raise ValueError("positive sizes required")
        self.size = block_size
        self.free_ids = list(range(blocks))
        self.data, self.refs, self.sequences = {}, {}, {}

    def create(self, name):
        if name in self.sequences:
            raise ValueError("sequence already exists")
        self.sequences[name] = []

    def _allocate(self, values=()):
        if not self.free_ids:
            raise MemoryError("KV pool exhausted")
        block = self.free_ids.pop()
        self.data[block] = list(values)
        self.refs[block] = 1
        return block

    def fork(self, source, target):
        if target in self.sequences:
            raise ValueError("target already exists")
        ids = self.sequences[source].copy()
        for block in ids:
            self.refs[block] += 1
        self.sequences[target] = ids

    def append(self, name, token):
        ids = self.sequences[name]
        if not ids or len(self.data[ids[-1]]) == self.size:
            ids.append(self._allocate())
        elif self.refs[ids[-1]] > 1:
            old = ids[-1]
            new = self._allocate(self.data[old])  # allocate before mutating
            self.refs[old] -= 1
            ids[-1] = new
        self.data[ids[-1]].append(token)

    def values(self, name):
        return [x for block in self.sequences[name] for x in self.data[block]]

    def release(self, name):
        for block in self.sequences.pop(name):
            self.refs[block] -= 1
            if self.refs[block] == 0:
                del self.refs[block], self.data[block]
                self.free_ids.append(block)

m = BlockManager(3, 2)
m.create('a'); m.append('a', 1); m.fork('a', 'b')
m.append('b', 2)
assert m.values('a') == [1] and m.values('b') == [1, 2]
m.append('a', 3); m.append('a', 4)
try:
    m.append('b', 5)
    raise AssertionError("expected exhaustion")
except MemoryError:
    pass
assert m.values('b') == [1, 2]
m.release('a'); m.release('b')
assert len(m.free_ids) == 3 and not m.refs
```

Appending is $O(1)$ normally and $O(B)$ on copy-on-write for block size B; fork/release scale with sequence blocks. Production systems add locks, stream/event synchronization, eviction, and tenant-safe cache keys. PagedAttention explains the allocation and sharing motivation.

### The ownership invariant prevents corruption

Every allocated physical block has a reference count equal to the number of sequence tables pointing to it. Forking copies only block IDs and increments counts. Appending into a shared partial block first allocates and copies it, then updates only the writer's sequence table. Full shared blocks are immutable and can remain shared indefinitely.

In the test, A and B initially share token 1. Appending token 2 to B must not alter A, so B receives a private partial block. Allocation happens before decrementing the old reference count, ensuring that exhaustion leaves the sequence unchanged. Releasing a sequence frees a block only when its final reference disappears. The example deliberately lacks eviction and GPU execution. A production manager must fence outstanding attention kernels before reusing memory, validate tenant/model cache identities, and coordinate concurrent allocation. Test failure during copy, repeated release, fork chains, and exhaustion at every append boundary.
