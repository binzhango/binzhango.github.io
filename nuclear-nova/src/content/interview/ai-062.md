## Question

What is catastrophic forgetting and how do you mitigate it during fine-tuning?

## Brief answer

Catastrophic forgetting is degradation of previously learned behavior during adaptation to new data. Reduce it with representative replay, smaller updates, regularization or parameter-efficient adaptation, while evaluating both new and retained capabilities.

## Detailed answer

A narrow support-ticket dataset can improve response style while hurting general reasoning or languages absent from that dataset. Mix carefully sampled retention data, lower the learning rate, stop on validation regressions, and compare adapters against full tuning. Keep held-out suites for important old tasks. A frozen backbone does not guarantee unchanged behavior because an adapter can still redirect outputs strongly. Accept tradeoffs explicitly instead of hiding them behind a single aggregate score.

Fine-tuning changes the function the model computes, not just a separate database of new facts. Gradients from a narrow dataset can move shared features toward patterns that help that dataset while weakening representations used elsewhere. A model trained only on terse support tickets might become worse at long explanations or switch languages inappropriately even though support accuracy improves.

Distinguish forgetting from overfitting and evaluation mismatch. First compare the original and adapted models on the same held-out target and retention suites. Then inspect whether prompt templates, tokenization or decoding changed. If the weights are responsible, reduce learning rate or update steps, mix representative retention examples, or constrain updates with adapters or regularization toward the starting model. A frozen backbone is helpful but does not prevent a large adapter from dominating outputs.

Use a two-axis release decision: target improvement and acceptable retention loss. Early stopping should consider both. For example, a checkpoint that improves target accuracy by three points while reducing a required language slice by ten points may be worse than an earlier checkpoint with a smaller target gain. Preserve the base model and separate adapters so rollback is straightforward. Replaying private historical data also requires an explicit retention and provenance policy rather than indiscriminately mixing every available record.
