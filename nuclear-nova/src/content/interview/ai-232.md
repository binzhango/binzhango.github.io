## Question

How do modern multimodal models get image and video understanding into an LLM, and what changes for video specifically?

## Brief answer

Image understanding usually introduces visual features through a projection into language-token space, cross-attention, or an integrated multimodal representation. Video additionally requires temporal sampling, synchronization and reasoning about order and motion.

## Detailed answer

A vision encoder plus projector can reuse pretrained components; LLaVA is a concrete example. Spatial resolution and compression determine whether small text and object counts remain recoverable. For video, preserve timestamps and align audio/transcripts, then retrieve or summarize clips hierarchically under a context budget. Independent frames can miss a fast event or confuse before/after relationships. Evaluate OCR, grounding and counting separately from temporal ordering, event boundaries and speaker/action association. Extra frames improve coverage only if the system retains useful timing and can process them within its latency budget.

### Follow visual evidence into generation

A vision encoder turns image patches into feature vectors. A projector maps them to a representation the language model can consume, or cross-attention lets language states query a separate visual representation. Multimodal training aligns these representations with tasks such as captioning, question answering, and grounding. If preprocessing has already erased small text, the language model cannot reconstruct it reliably from fluency.

Video adds a time axis and a sampling decision. One frame per second may capture a scene but miss a brief handoff; more frames increase token and compute cost. Preserve timestamps and audio alignment so “before,” “after,” duration, and speaker association are grounded in actual sequence information. Use coarse retrieval to find relevant intervals, then inspect denser frames where the question requires detail. Evaluate temporal tasks with counterfactual order changes: a model relying only on individual-frame appearance should fail when actions are reversed. Report evidence coverage separately from reasoning quality so missed events are not hidden by plausible summaries.
