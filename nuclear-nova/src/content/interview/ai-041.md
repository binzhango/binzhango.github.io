## Question

How do you handle tables, figures and multi-column PDFs in a retrieval pipeline?

## Brief answer

Preserve document layout and provenance instead of flattening a PDF into one text stream. Extract reading order, table structure, captions and page coordinates, using OCR only where native text is missing or unreliable.

## Detailed answer

A table chunk should retain row labels, column headers, units and footnotes; a figure needs its caption and a link to the original image. Multi-column pages require layout-aware ordering before chunking. Store page numbers and bounding boxes with each passage so citations can highlight the evidence. Test extraction on representative scans and complex layouts, not just searchable PDFs. Route low-confidence pages for review rather than indexing plausible but corrupted text.

A useful ingestion record separates content from geometry. For each page, store text spans with reading-order IDs and bounding boxes, tables with cell coordinates and headers, and figures with captions and image references. Use native text extraction when reliable, then OCR for scanned regions or broken character maps. Compare OCR confidence with layout and language checks instead of assuming searchable text is correct.

For a table showing “Revenue, USD millions,” retain the unit and column year with every retrievable row. The isolated cell `42` is not meaningful evidence. A chart may require a vision model or structured extraction, but generated descriptions should be marked as derived and linked to the original figure. Multi-column reading order must avoid interleaving unrelated sentences across columns.

After extraction, run checks for missing pages, duplicated headers, garbled characters and inconsistent table widths. Maintain an exception queue for low-confidence documents and a reproducible parser version so fixes can reprocess affected files. Evaluate on questions that require footnotes, captions and cross-page tables, not only paragraphs. Citation rendering should let the reader locate the exact source region; if a model invents an interpretation of an ambiguous figure, a precise page link alone does not make that interpretation supported.
