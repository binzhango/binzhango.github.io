## Question

Budget the latency for a real-time voice agent: VAD, ASR, LLM, TTS, network. Where does the time go?

## Brief answer

Budget latency from the end of a user’s utterance to the first useful audio response, then track sustained streaming delay. Endpoint detection, network transit, ASR finalization, model TTFT and TTS startup can all dominate.

## Detailed answer

As a hypothetical budget, 150 ms endpointing, 80 ms network, 100 ms ASR finalization, 250 ms model startup and 120 ms TTS startup sum to 700 ms if sequential. Streaming can overlap stages, so model the critical path rather than blindly adding every duration. Measure percentiles and interruption behavior under real audio conditions. Long silence thresholds feel sluggish; overly aggressive endpointing cuts users off.

Draw a timeline from the user's last meaningful sound to audible assistant speech. Voice activity detection estimates speech boundaries; endpointing decides when the turn is complete. ASR may already have a partial transcript, but finalization can revise words. The LLM then produces enough stable text for TTS, which synthesizes and buffers initial audio before network playback.

Some work overlaps: streaming ASR runs while the user speaks, and TTS can begin before the full answer is generated. The critical path is therefore the set of dependencies that delay first useful audio, not the sum of every component's total runtime. Speculatively starting from an unstable transcript can save time but waste work or answer the wrong question if the final words change meaning.

Track end-of-speech detection delay, first-text latency, first-audio latency and underruns separately. Measure p95/p99 under network jitter, background noise and long user pauses. Tune endpointing by language and interaction style so natural hesitation is not mistaken for completion. Also measure barge-in stop latency: a fast initial response that continues talking over the user still feels poor. The illustrative 700-ms budget is a planning model; deployment targets should be validated with real conversational trials.
