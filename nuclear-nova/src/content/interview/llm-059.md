## Question

What are the application scenarios for cross-attention?

## Brief answer

Cross-attention is used in encoder-decoder translation, summarization, speech-to-text, multimodal fusion, and text-conditioned diffusion models.

## Detailed answer

In a speech encoder-decoder, output text states query encoded audio. In a text-conditioned diffusion network, visual features can query text embeddings. Some retrieval architectures cross-attend to retrieved representations, but conventional prompt-based RAG simply places retrieved text in a decoder's input. Do not assume every RAG or multimodal implementation includes a dedicated cross-attention layer.

In speech recognition, an encoder converts audio frames into acoustic representations. Each decoder text position queries those representations to select information relevant to the next token. Different audio and text lengths are natural: several frames may correspond to one character or word, and the alignment need not be supplied explicitly for every pair.

In text-conditioned image generation, a visual feature location can query text features to receive information about objects or attributes. The direction matters: visual queries reading text values produces one conditioned output per visual location, not one per text token. In document summarization, decoder queries read source representations to combine information from different paragraphs.

Choose the interaction according to which output locations need conditioning. If two modalities must update one another, an architecture may need attention in both directions or multiple fusion stages. If the goal is simply to answer using a few text excerpts, placing them in a prompt may be simpler and requires no new cross-attention module. Evaluate alignment and output correctness; attention maps alone do not establish that the model grounded every claim in the intended source.
