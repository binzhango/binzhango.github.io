## Question

How do vision-language models get images into an LLM: projector, cross-attention, or native tokens?

## Brief answer

A vision-language model can project image-encoder features into the language model’s embedding space, expose visual features through cross-attention, or process image-related tokens within a more integrated multimodal architecture.

## Detailed answer

Projector approaches can reuse strong pretrained encoders with a relatively simple bridge. Cross-attention gives language tokens selective access to visual representations without placing all features in the same token stream. Integrated designs change training and representation more broadly. Patch size, image resolution and token compression affect cost and fine-detail accuracy. Evaluate OCR, spatial relations and grounding separately; recognizing an object is different from correctly locating or counting it.

A common projector pipeline first divides the image into patches, encodes them with a vision model, then maps the resulting feature width into the language model's hidden dimension. The projected vectors behave like additional context tokens. A small bridge can reuse pretrained components, but it must be trained to align visual features with language behavior.

Cross-attention instead keeps visual representations in a separate memory that language states query at selected layers. This can control how much image information is repeatedly mixed into text processing. More integrated models train on mixed modality representations from the outset. “Native tokens” does not necessarily mean raw pixels are treated as ordinary text tokens; the image still needs a learned representation and an associated positional structure.

Resolution creates a cost-quality tradeoff. Increasing patches may preserve small text or distant objects but lengthens the visual sequence and increases attention work. Compression can reduce tokens while discarding details needed for counting or OCR. Evaluate image understanding with targeted tasks: identify objects, read fine text, compare regions, count repeated items and ground answers to locations. A fluent caption is weak evidence for precise spatial reasoning, and a model may rely on language priors when the image is ambiguous.
