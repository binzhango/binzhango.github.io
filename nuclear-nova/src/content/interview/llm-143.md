## Question

How does HyDE work, when can it outperform standard dense retrieval, and what are its limitations?

## Brief answer

HyDE generates a hypothetical answer document, embeds it, and retrieves real documents near that representation. It can bridge a short question's vocabulary gap, but the generated passage is a search aid, never factual evidence.

## Detailed answer

HyDE starts with the user's question and asks a generative model to write a plausible relevant passage. A document encoder maps that passage into the same vector space used for actual corpus documents. Nearest-neighbor search then retrieves real passages, which must supply the evidence for the final answer. This can help when document-like wording matches the encoder's learned representation better than a short query. It requires no claim that the hypothetical passage itself is correct.

The key move is to search with a document-like representation rather than only a short question. For “Why does this battery lose capacity in the cold?”, a hypothetical passage may mention temperature, electrochemical reaction rates, and internal resistance. Encoding that richer text can place the query near relevant explanatory documents even when the question uses few of their terms.

The generated passage can also be wrong. If the query names a rare component and the model assumes a different device, the embedding may point toward a coherent but irrelevant cluster. Preserve the original query and exact identifiers, and compare direct dense or hybrid candidates alongside the hypothetical-document candidates. Rerank actual passages against the original question.

A useful evaluation separates retrieval improvement from generation fluency: record whether the real answer-bearing source reaches the candidate set, then evaluate answers generated only from those real sources. Include rare entities and ambiguous queries, where invented details are particularly risky. HyDE adds a generation step and associated latency, so use it when improved recall justifies the cost. Never cite the hypothetical passage as if it were a retrieved factual source.
