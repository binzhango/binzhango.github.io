## Question

Write a streaming SSE/JSON parser that handles arbitrary chunk boundaries.

## Brief answer

Decode UTF-8 incrementally, recognize SSE line endings even when split across chunks, collect `data:` lines until a blank line, and only then parse the event payload as JSON. Network chunks are unrelated to UTF-8 character, line, event or JSON boundaries. Treat reconnection IDs and retry instructions separately from payload parsing.

## Detailed answer

This parser implements JSON-bearing SSE data events, supports CR, LF and CRLF, comments, a leading BOM and `[DONE]`. It deliberately discards an unterminated event at EOF, matching SSE dispatch rules.

```python
import codecs, json

class SSEJSON:
    def __init__(self):
        self.decoder = codecs.getincrementaldecoder('utf-8-sig')()
        self.buffer, self.data, self.has_data = '', [], False
    def feed(self, chunk, final=False):
        self.buffer += self.decoder.decode(chunk, final=final)
        out = []
        while True:
            positions = [p for p in (self.buffer.find('\r'), self.buffer.find('\n')) if p >= 0]
            if not positions: break
            i = min(positions)
            if self.buffer[i] == '\r' and i == len(self.buffer)-1 and not final: break
            n = 2 if self.buffer[i:i+2] == '\r\n' else 1
            line, self.buffer = self.buffer[:i], self.buffer[i+n:]
            if not line:
                if self.has_data:
                    text = '\n'.join(self.data)
                    out.append(None if text == '[DONE]' else json.loads(text))
                self.data, self.has_data = [], False
            elif not line.startswith(':'):
                field, sep, value = line.partition(':')
                if value.startswith(' '): value = value[1:]
                if field == 'data':
                    self.has_data = True; self.data.append(value if sep else '')
        if final: self.buffer, self.data, self.has_data = '', [], False
        return out

payload = 'data: {"text":"é"}\r\n\r\n'.encode()
for cut in range(len(payload)+1):
    parser = SSEJSON()
    assert parser.feed(payload[:cut]) + parser.feed(payload[cut:], True) == [{'text':'é'}]
```

A production parser also bounds event size, reports malformed JSON with context, and handles event names, IDs and reconnect policy. Raw concatenated JSON is a different framing protocol.

There are four boundaries to keep separate: byte chunks, Unicode characters, text lines and SSE events. A multibyte character may span two network reads; a CRLF line ending may also split; an event may contain several `data:` lines. Only a blank line dispatches the accumulated payload. Parsing each network chunk as JSON therefore fails even when the server is perfectly valid.

The example tries every two-part split of a payload containing `é`, exercising both byte decoding and framing. Add tests for many one-byte chunks, comments, multiple events in one chunk, empty data, malformed JSON and unfinished EOF. The parser handles a JSON-bearing subset of SSE, so an empty data event is invalid JSON even though it is valid SSE. The repeated string concatenation and scanning are simple reference logic and can be inefficient for extremely large events; impose size limits and use a more incremental buffer for production. Reconnection and event-ID deduplication belong above this payload parser.
