## Question

Which normalization method is used in different LLM architectures?

## Brief answer

Normalization varies by checkpoint: BERT uses post-LayerNorm, GPT-2 uses pre-LayerNorm, and Llama uses pre-RMSNorm.

## Detailed answer

The original Transformer uses post-LayerNorm. T5 uses a mean-free normalization closely related to RMSNorm, and Gemma 2 adds normalization around sublayers beyond a simple pre-norm layout. Therefore, “all modern LLMs use pre-RMSNorm” is too broad. Confirm the normalization class, placement, epsilon, and learned scale/bias in the model configuration and implementation.

A checkpoint's normalization choice has two independent parts: the statistic being computed and its location in the block. Reading only a configuration field called `layer_norm_eps` does not establish that the implementation subtracts the mean, and seeing an RMSNorm class does not establish that there is only one normalization per sublayer.

Trace one block in order: input state, normalization, attention, residual addition, normalization, FFN, residual addition, and any output normalization. Then inspect whether each normalization has learned scale, learned bias, or an offset convention for the scale. This tells you what happens to a token vector and which checkpoint tensors are expected.

For example, implementing a BERT-style post-norm block using a GPT-2-style pre-norm order while loading the same tensor shapes can pass shape checks yet compute a different function. Likewise, a different epsilon can matter near a low-variance input. The named model examples refer to specific published designs. New releases and converted checkpoints should be checked individually rather than inheriting assumptions from the family name.
