## Question

How do GRU cells work, and how do they address the vanishing gradient problem? How does a BiLSTM work?

## Brief answer

A GRU uses update and reset gates to control how old state and new candidate information are combined. The additive state path helps gradients propagate, though it does not eliminate vanishing or exploding gradients. A bidirectional LSTM runs separate recurrent networks forward and backward and combines their states, gaining future context at the cost of causal streaming capability.

## Detailed answer

One GRU convention is $r_t=\sigma(W_rx_t+U_rh_{t-1})$, $z_t=\sigma(W_zx_t+U_zh_{t-1})$, $\tilde h_t=\tanh(W_hx_t+U_h(r_t\odot h_{t-1}))$, and $h_t=(1-z_t)\odot h_{t-1}+z_t\odot\tilde h_t$. Some implementations reverse the update-gate convention or place reset multiplication differently; match equations to code.

When the update gate preserves state, the recurrence offers a near-identity route for information and gradients. Long sequences still benefit from gradient clipping, normalization, and careful initialization. BiLSTM concatenates or otherwise combines forward and reverse outputs for tagging or offline sequence analysis. It cannot use the full reverse pass for a live prefix without waiting for future input, so causal tasks need a different latency/accuracy compromise.

### Gates provide a controllable memory path

In the convention above, an update gate near zero copies the old hidden state, while a gate near one replaces it with the candidate. The reset gate controls how much old state contributes when forming that candidate. This allows a GRU to preserve a useful signal across many steps without repeatedly multiplying it by an unconstrained recurrent matrix. It reduces a common source of vanishing gradients but does not guarantee perfect long-term memory.

A BiLSTM runs one recurrent network left to right and another right to left, then combines their outputs at each position. In “the bank raised rates,” future words help disambiguate “bank” for tagging or extraction. In streaming speech or next-token generation, those future words are not yet available, so a full bidirectional pass would violate causality or add waiting time. Compare GRU's simpler state with LSTM's separate cell and hidden state using actual task accuracy, training stability, and inference latency.
