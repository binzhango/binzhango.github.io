## Question

How to select datasets effectively?

## Brief answer

Select datasets according to the target task and observed failure modes, then test whether each source adds measurable value.

## Detailed answer

Audit relevance, answer quality, licensing, duplication, contamination, and coverage. Sample and inspect actual records rather than trusting dataset names or leaderboard popularity. Start with a clean baseline mixture and add sources through controlled ablations. Keep selection decisions separate from the final test set, and monitor whether gains on one slice introduce regressions elsewhere.

Build a candidate-source inventory tied to actual errors. If the baseline fails multi-turn tool recovery, adding another large set of single-turn general questions may not help. Sample records from a source and check whether they supply the missing behavior with correct, usable targets. Dataset size and popularity are weak proxies for that fit.

Deduplicate across candidate sources before making splits, because different datasets can contain copies of the same underlying benchmark or document. Review licensing, source permissions, language coverage, date sensitivity, and answer quality. Preserve task and source metadata so changes in mixture remain inspectable.

Run controlled additions: train a baseline mixture, add one source or replace an equal token budget, and evaluate target gains and regressions using the same development set. An apparent improvement from simply increasing total training steps is different from evidence that the new source is better. Use the final test only after selection. Retain sources that add independent useful signal, and remove those that teach incompatible formats, duplicate existing material, or improve a benchmark through contamination rather than generalization.
