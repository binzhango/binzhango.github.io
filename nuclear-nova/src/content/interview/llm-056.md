## Question

Explain Cross-Attention.

## Brief answer

Cross-attention computes queries from a target representation and keys/values from a separate source representation.

## Detailed answer

For $X\in\mathbb R^{n_q\times d_x}$ and $Y\in\mathbb R^{n_k\times d_y}$:

$$
Q=XW_Q,\quad K=YW_K,\quad V=YW_V,\qquad
O=\operatorname{softmax}\left(\frac{QK^\top}{\sqrt{d_k}}+M\right)V.
$$

The softmax runs over source positions. $M$ masks unavailable keys, such as source padding. Query and key projections must share dimension $d_k$, but the original sequences can have different feature widths. The result has one output vector per query position.

If three target positions query five source positions, the score matrix is $3\times5$. Each row becomes a distribution over the five source values, so the result contains three output vectors. Source and target lengths need not match, and multiple targets can attend to the same source region. Padding masks remove nonexistent source entries before normalization.

The scale $1/\sqrt{d_k}$ controls the magnitude of dot products as query/key width increases under common initialization assumptions. Very large logits can make softmax extremely concentrated and produce difficult gradients. This scaling does not replace normalization elsewhere in the network or ensure calibrated probabilities.

For a simple weighted read, if one target assigns probabilities $(0.75,0.25)$ to two values $(2,0)$ and $(0,4)$, its output is $(1.5,1)$. That output is a learned mixture of source features, not necessarily an interpretable extracted source token. Multi-head cross-attention repeats the process in separate projected spaces and combines the head outputs. During incremental decoding, fixed source keys and values can be projected once and reused; only the target query changes each step.
