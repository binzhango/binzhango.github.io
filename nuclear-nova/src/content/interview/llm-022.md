## Question

What are representative open-weight LLM families, and how do they differ from fully open-source releases?

## Brief answer

Well-known released-weight families include Llama, Mistral/Mixtral, Gemma, Phi, Qwen, DeepSeek, Falcon, and OLMo. “Open weights” and “open source” are not interchangeable.

## Detailed answer

This is a representative family list, not a ranking or exhaustive catalog of the newest releases. Check each checkpoint's license, model card, architecture, training-data disclosure, and permitted uses. A family can contain dense, mixture-of-experts, and multimodal variants; do not assign every release the properties of one model. Start with the official Llama, Qwen, DeepSeek, and OLMo resources.

Compare releases along separate dimensions. Weights let a user run inference locally. Training and inference code help inspect and reproduce implementation behavior. Tokenizers, data descriptions, data-processing code, and intermediate checkpoints improve reproducibility. A license determines permitted use and redistribution; downloading a weight file alone does not answer those questions.

For an application, first establish the required capability and deployment budget, then compare exact checkpoints on the same task. A dense model activates most parameters for each token; a mixture-of-experts model can activate a subset but still require storage and communication for its experts. A multimodal model also needs the corresponding encoders and preprocessing, so the text parameter count alone does not describe the whole system.

For example, choosing a model for offline document extraction requires checking language coverage, structured-output reliability, memory at the desired context length, and whether the intended distribution is permitted. Keep the checkpoint revision and tokenizer together. The family names in the brief answer are representative examples, not a current performance ranking or a claim that every version shares one architecture or license.
