## Question

Given an array nums of n integers where n > 1, return an output array (product of array except self).

## Brief answer

Compute prefix products into the output, then multiply by suffix products in a reverse pass. This avoids division, handles zeros naturally and runs in linear time with constant auxiliary space beyond the output. Define overflow behavior for fixed-width languages; Python integers grow as needed.

## Detailed answer

```python
def product_except_self(nums):
    out = [1] * len(nums)
    prefix = 1
    for i, value in enumerate(nums):
        out[i] = prefix
        prefix *= value
    suffix = 1
    for i in range(len(nums)-1, -1, -1):
        out[i] *= suffix
        suffix *= nums[i]
    return out

assert product_except_self([1,2,3,4]) == [24,12,8,6]
assert product_except_self([0,2,3]) == [6,0,0]
assert product_except_self([0,0,3]) == [0,0,0]
assert product_except_self([-1,2,-3]) == [-6,3,-2]
```

At index i, the first pass stores the product strictly before i; the second contributes the product strictly after i. Their product excludes exactly the current element. The input promises more than one element, but the function also returns an empty list for empty input and `[1]` for a singleton under the empty-product convention. State that convention if generalizing the contract.

Trace `[1,2,3,4]`: the first pass writes `[1,1,2,6]`, the products to the left of each position. The reverse pass multiplies by suffix products `[24,12,4,1]`, giving `[24,12,8,6]`. The current element is excluded because each accumulator is applied before incorporating that element.

Zeros need no special branch. With one zero, every position except the zero includes it in either a prefix or suffix, producing zero; the zero's own output multiplies all nonzero elements. With two zeros, every output includes at least one zero. Division-based approaches need separate handling for these cases and can introduce numerical issues.

The usual $O(n)$ time assumes constant-cost arithmetic. Python's arbitrary-precision products grow in bit length, so actual cost depends on values. In fixed-width languages, define overflow or use a wider checked type. Auxiliary state beyond the output is two accumulators, but the output itself is necessarily linear in input size.
