## Question

A regional government wants an assistant in a low-resource language with only a few thousand sentences of clean text. How do you adapt a model to it?

## Brief answer

A few thousand clean sentences are too little to train a capable language model from scratch. Start with a multilingual model that has relevant script and related-language coverage, prioritize a narrow use case, and invest in native-speaker evaluation and trusted retrieval. Use careful adaptation only after measuring the base model's specific weaknesses.

## Detailed answer

Audit corpus rights, dialect coverage, writing conventions, and tokenizer fragmentation. Reserve an independent evaluation set before augmentation. Collect high-value examples for common intents, names, terminology, and error cases; compare prompting, retrieval, and parameter-efficient fine-tuning at the same test conditions.

Translated or synthetic examples can increase coverage, but fluent speakers must check meaning and reject unnatural patterns. Use related languages as transfer sources cautiously because similar scripts do not guarantee equivalent grammar or social meaning. For factual services, retrieve approved documents and abstain when coverage is absent. Test comprehension and generation separately, including dialects and low-literacy phrasing. If the model cannot reliably understand the language, ship a narrower assisted workflow rather than masking the gap with confident output.

### Spend the small dataset carefully

With only a few thousand clean sentences, a large unconstrained fine-tune can memorize examples and degrade existing capabilities. Divide by source or speaker before augmentation, reserve a native evaluation set, and create a narrow task inventory. A few hundred carefully checked examples of the actual service workflow may be more valuable than thousands of generic translated sentences.

Begin with a multilingual model that already shows some comprehension of the language. Measure whether failures come from script tokenization, missing domain knowledge, or instruction following. Retrieve approved factual documents for knowledge gaps; use a small adapter and conservative training for recurring task behavior. If comprehension is weak, collect additional native text and aligned examples before expanding scope. Include a human-assisted path and questions that should trigger clarification. Report native-rater agreement and uncertainty on small evaluation samples instead of presenting a single noisy accuracy as proof of language support.
