## Question

A Copilot chat feature has a p95 budget of 3 seconds to first useful content. Where does the time go, and how do you cut it?

## Brief answer

Trace the critical path from request arrival to genuinely useful output: queueing, identity and authorization, retrieval, tool calls, prompt construction, prefill, and first generated content. Streaming an empty acknowledgment does not satisfy a useful-content SLO. Optimize the largest measured contributors while preserving permissions and answer quality.

## Detailed answer

Allocate a three-second budget across observed dependencies, then measure p95 end to end rather than adding independent component p95 values. Cache stable authorized results, run independent retrieval calls concurrently, cap fan-out, and set deadlines with fallbacks. Use a smaller model for routing and a suitable model for generation; shorten prompts and reuse exact prefixes where safe.

Separate cold starts, long histories, and overloaded queues from normal traffic. Start rendering useful grounded content once available, but do not stream unsupported claims before retrieval finishes. Cancel downstream work on disconnect. Load-test realistic concurrency and permission distributions. Track first useful content, final completion, citation correctness, and abandonment together so a latency optimization cannot win by skipping required work.

### An illustrative critical-path budget

A starting budget might allocate 100 ms to gateway and authorization, 600 ms to retrieval/reranking, 200 ms to prompt assembly and queueing, 1,200 ms to prefill and early generation, and 900 ms of headroom. These are planning assumptions, not measured guarantees. If email and document retrieval are independent, running them concurrently makes their contribution closer to the slower branch rather than their sum.

Trace individual requests with correlation IDs and record time spent waiting versus computing. A p95 regression concentrated in cold model starts needs a different fix from one caused by a slow permissions service. Apply dependency deadlines and return a useful scoped answer when an optional source fails, while making the missing scope clear. Do not bypass security checks or generate unsupported filler to meet the clock. Load-test arrival bursts; queue delay often grows sharply before average GPU utilization looks alarming.
