# RAG Engineering diagrams

The `.drawio` files contain native editable shapes, labels, and connectors. Light and dark versions use explicit palettes. Public SVGs also embed their corresponding native XML.

- `author-diagrams.py` creates the initial native diagrams and manifest. Running it again overwrites manual XML edits.
- `render-diagrams.mjs` exports the existing XML with the official draw.io viewer runtime through `Graph.getSvg`. It does not regenerate the source XML.
- `export-receipt.json` records the runtime hash, cell counts, image dimensions, and exported SVG hashes.
- `public/diagrams/rag-engineering/rag-engineering.drawio` is the eleven-page light-theme bundle.

To export after editing the XML, download the official viewer runtime to a temporary path and pass it to the renderer:

```sh
curl --fail -L https://viewer.diagrams.net/js/viewer-static.min.js -o /tmp/rag-drawio-viewer.js
node tools/drawio/rag-engineering/render-diagrams.mjs /tmp/rag-drawio-viewer.js
```

Run from `nuclear-nova`. Chrome and the repository's Playwright dependency are required. Inspect the SVGs at article width and on mobile after export; cell counts cannot establish visual quality. If adding or removing nodes, update the manifest's expected topology. Copy manually edited XML to the public download directory before building, and keep the multi-page bundle synchronized.

The full system view is generated by Archify from `tools/archify/rag-evidence-path.dataflow.json`. Its receipt is stored alongside the specification.
