DECODE PHASE
Output: generates tokens one-by-one
  • Processes ONE token per step (autoregressive)
  • Memory-bandwidth-bound (low GPU utilization ~30-40%)
  • Long duration (hundreds of steps)
  • Reads: KV cache grows with each new token
